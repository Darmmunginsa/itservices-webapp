# สิทธิ์การเข้าถึงหน้า (รายคน) — หน้าจัดการใหม่

## ปัญหาเดิม

ตารางคน × หน้า **21 คอลัมน์** ต้องเลื่อนแนวนอนจนสุดถึงจะเห็นครบ และ**บันทึกได้ทีละคน**
ตั้งสิทธิ์ให้ทีม 10 คน = เลื่อนไปมา 10 รอบ กดบันทึก 10 ครั้ง

## ตอนนี้

```
┌ รายชื่อ ──────────┐ ┌ สมชาย ใจดี ─────────────── [ทั้งหมด] [ล้าง] [คัดลอกจาก… ▾] [บันทึกคนนี้] ┐
│ 🔍 ค้นหา          │ │ ▸ หน้าหลัก  3/3      [เลือกทั้งกลุ่ม]                                 │
│ ● สมชาย  12/21    │ │   ☑ แจ้งงาน  ☑ งานของฉัน  ☑ My Tracking                             │
│   อารีย์  ยังไม่กำหนด│ │ ▸ งาน  4/6                                                          │
│   บอส  Admin      │ │   ☑ โครงการ  ☑ Dashboard  ☐ รายงาน  …                                │
│ + เพิ่มด้วยอีเมล    │ │ ▸ ข้อมูล / ทะเบียน …   ▸ ระบบ …                                     │
└───────────────────┘ └────────────────────────────────────────────────────────────────────────┘
                                                        [✔ บันทึกที่แก้ทั้งหมด (3)]
```

- **ซ้าย** เลือกคน · **ขวา** หน้าทั้งหมดจัดกลุ่ม 4 กลุ่มในจอเดียว — **ไม่มีเลื่อนแนวนอน**
- **บันทึกที่แก้ทั้งหมด (N)** — แก้กี่คนก็ได้ แล้วกดครั้งเดียว · จุดสีเหลืองที่ชื่อ = แก้แล้วยังไม่บันทึก
- **คัดลอกสิทธิ์จาก…** — ตั้งคนใหม่ให้เหมือนคนในทีมเดียวกันได้ทันที ไม่ต้องติ๊ก 21 ช่อง
- เลือก/ล้าง**ทั้งกลุ่ม**ได้ · แต่ละคนเห็น "เข้าได้ N/21 หน้า" ในรายชื่อ
- role **Admin** เข้าได้ทุกหน้าเสมอ กำหนดไม่ได้ (กันล็อกตัวเองออก) — เหมือนเดิม

## บันทึกทีเดียวหลายคน — ทำไมต้องรู้ว่าใคร "แก้แล้ว"

ถ้าบันทึกทุกคนในรายการ: เสียเวลา + เขียนทับแถวที่ไม่ได้แก้ · ถ้าบันทึกแค่คนที่เลือกอยู่: คนอื่นที่แก้ไว้หายเงียบ
จึงเทียบ**ร่างกับที่บันทึกไว้จริง**ทีละคน (`dirtyEmails`) — คนที่ยังไม่มีแถวและร่างว่างไม่นับว่าแก้

บันทึก**ทีละคนตามลำดับ** ไม่ยิงพร้อมกัน — กัน SharePoint throttle · ล้มบางคนบอกตัวเลข ไม่กลบเป็นสำเร็จ
