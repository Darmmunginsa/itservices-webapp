# สิทธิ์การเข้าถึงหน้า (รายคน) — หน้าจัดการใหม่

## ปัญหาเดิม

ตารางคน × หน้า **21 คอลัมน์** ต้องเลื่อนแนวนอนจนสุดถึงจะเห็นครบ และ**บันทึกได้ทีละคน**
ตั้งสิทธิ์ให้ทีม 10 คน = เลื่อนไปมา 10 รอบ กดบันทึก 10 ครั้ง

## ตอนนี้

```
┌ รายชื่อ ──────────┐ ┌ สมชาย ใจดี ─────────────── [ทั้งหมด] [ล้าง] [คัดลอกจาก… ▾] [บันทึกคนนี้] ┐
│ 🔍 ค้นหา          │ │ ▸ หน้าหลัก  3/3      [เลือกทั้งกลุ่ม]                                 │
│ ● สมชาย  12/21    │ │   ☑ แจ้งงาน  ☑ งานของฉัน  ☑ My Tracking                             │
│   อารีย์  ยังไม่กำหนด│ │ ▸ งาน  4/6                                                          │
│   บอส  Admin      │ │   ☑ โครงการ  ☑ Dashboard  ☐ รายงาน  …                                │
│ + เพิ่มด้วยอีเมล    │ │ ▸ ข้อมูล / ทะเบียน …   ▸ ระบบ …                                     │
└───────────────────┘ └────────────────────────────────────────────────────────────────────────┘
                                                        [✔ บันทึกที่แก้ทั้งหมด (3)]
```

- **ซ้าย** เลือกคน · **ขวา** หน้าทั้งหมดจัดกลุ่ม 4 กลุ่มในจอเดียว — **ไม่มีเลื่อนแนวนอน**
- **บันทึกที่แก้ทั้งหมด (N)** — แก้กี่คนก็ได้ แล้วกดครั้งเดียว · จุดสีเหลืองที่ชื่อ = แก้แล้วยังไม่บันทึก
- **คัดลอกสิทธิ์จาก…** — ตั้งคนใหม่ให้เหมือนคนในทีมเดียวกันได้ทันที ไม่ต้องติ๊ก 21 ช่อง
- เลือก/ล้าง**ทั้งกลุ่ม**ได้ · แต่ละคนเห็น "เข้าได้ N/21 หน้า" ในรายชื่อ
- role **Admin** เข้าได้ทุกหน้าเสมอ กำหนดไม่ได้ (กันล็อกตัวเองออก) — เหมือนเดิม

## บันทึกทีเดียวหลายคน — ทำไมต้องรู้ว่าใคร "แก้แล้ว"

ถ้าบันทึกทุกคนในรายการ: เสียเวลา + เขียนทับแถวที่ไม่ได้แก้ · ถ้าบันทึกแค่คนที่เลือกอยู่: คนอื่นที่แก้ไว้หายเงียบ
จึงเทียบ**ร่างกับที่บันทึกไว้จริง**ทีละคน (`dirtyEmails`) — คนที่ยังไม่มีแถวและร่างว่างไม่นับว่าแก้

บันทึก**ทีละคนตามลำดับ** ไม่ยิงพร้อมกัน — กัน SharePoint throttle · ล้มบางคนบอกตัวเลข ไม่กลบเป็นสำเร็จ

## ช่อง "แก้ไขได้" ต่อหน้า

**ปัญหา:** บางคนควรแก้ทะเบียน (Assets, ลูกค้า, Vendor…) ได้เท่า Admin **เฉพาะบางหน้า**
แต่เดิมสิทธิ์แก้ผูกกับ role ทั้งคน — จะให้แก้ Assets ต้องยกเป็น Boss ซึ่งปลดล็อกหน้าอื่นตามไปหมด

**ตอนนี้:** แต่ละหน้ามี 2 ช่อง

```
☑ IT Assets   ✏️☑      ← ดูได้ + แก้ไขได้
☑ Portals     ✏️☐      ← ดูได้อย่างเดียว
☑ My Tracking          ← หน้านี้ไม่มีอะไรให้ปลดล็อก จึงไม่มีดินสอ
```

- **ติ๊กแก้ = ติ๊กดูให้เอง** · เลิกดู = เลิกแก้ด้วย (แก้โดยไม่เห็นหน้า ไม่มีความหมาย)
- ชี้ที่ดินสอ = บอกว่าหน้านั้นปลดล็อกอะไร (ข้อความอยู่ใน `edit` ของ `config/pages.ts`)
- ปุ่ม **แก้ได้ทั้งหมด** / **แก้ได้ทั้งกลุ่ม** · รายชื่อโชว์ "เข้าได้ 15/20 · แก้ได้ 3" · คัดลอกสิทธิ์พาช่องแก้มาด้วย

### "แก้ไขได้" หมายถึงอะไรในแต่ละหน้า

| หน้า | ติ๊กแล้วทำได้เพิ่ม | ที่ยังตาม role |
|---|---|---|
| โครงการ | สร้างโครงการใหม่ | เห็นทุกโครงการ (Boss/Admin) |
| Agent Dashboard | มอบหมาย / รับงานแทนทีม | ส่วน Supervisor |
| รายงาน PM | จัดการเทมเพลต | — |
| IT Assets | เพิ่ม / แก้ / ลบ ทรัพย์สิน + อะไหล่ | — |
| Vendor Contracts · Portals · ลูกค้า | เพิ่ม / แก้ | — |
| คลังความรู้ | เขียน / แก้บทความ | **เผยแพร่** (Supervisor+) |
| แหล่งอ้างอิง | เพิ่ม / แก้ | **ลบ** (Boss/Admin) |
| ผังองค์กร | เปลี่ยนรูปให้คนอื่น | — |
| ความปลอดภัยอีเมล | จัดการรายงาน Phishing | — |

หน้าที่**ไม่มี**ช่องนี้: แจ้งงาน · งานของฉัน · My Tracking · Tools & Notes / ทักษะ (คุมด้วยความเป็นเจ้าของอยู่แล้ว) ·
รายงาน (ดูอย่างเดียว) · Admin / Activity / Diagnostic

> **เพิ่มให้อย่างเดียว** — คนที่ role ทำได้อยู่แล้ว ไม่มีทางเสียสิทธิ์จากช่องนี้ · role Admin แก้ได้ทุกหน้าเสมอ

### เก็บอย่างไร — ไม่ต้องแก้ SharePoint

คอลัมน์เดิม `AllowedPages`: `assets:edit,portals,contracts` — ต่อท้าย `:edit` = แก้ได้ด้วย
แถวเก่าที่ไม่มี `:edit` อ่านได้เหมือนเดิม = ดูอย่างเดียว

เลือกแบบนี้แทนเพิ่มคอลัมน์ใหม่ เพราะ `spGet` ที่ select คอลัมน์ที่ยังไม่มีจะล้มทั้งคำขอ →
ทุกคนตกไป fallback ตาม role จนกว่าจะเพิ่มคอลัมน์ · แบบต่อท้ายไม่มีช่วง "ครึ่งทาง" นั้น
