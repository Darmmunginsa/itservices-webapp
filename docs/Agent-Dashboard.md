# Agent Dashboard — Ticket / Incident / Task

## ปัญหาเดิม

หน้านี้เห็นแค่ **Ticket** ซึ่งเป็นแค่ส่วนเดียวของงานที่คนหนึ่งถืออยู่จริง
ตัวเลขบนหน้าจึงบอกภาระงานไม่ครบ และหัวหน้าที่ใช้หน้านี้จ่ายงาน
ก็ตัดสินใจจากข้อมูลครึ่งเดียว

## แท็บ 3 ชนิด

```
[ 🎫 Ticket (12) ]  [ ⚠ Incident (3) ]  [ ☑ Task (7) ]
```

**ตัวเลขบนแท็บคือ "งานที่ยังไม่จบ"** ไม่ใช่จำนวนทั้งหมด — และติดอยู่ตลอด
ไม่ต้องกดเข้าไปดูว่ามีงานค้างไหม ถ้าตัวเลขซ่อนอยู่หลังแท็บ แท็บที่ไม่ได้เปิดก็เท่ากับไม่มีอยู่

ขอบเขตข้อมูลเหมือนเดิม: **Supervisor / Boss / Admin เห็นทั้งหมด · Agent เห็นเฉพาะที่ตัวเองถือ**

## คอลัมน์ที่ต่างกันตามชนิด

| ชนิด | ความเร่งด่วน | เส้นตาย | ผู้เกี่ยวข้อง |
|---|---|---|---|
| Ticket | Priority | กำหนดส่ง | ผู้แจ้ง |
| Incident | **Severity** | **ครบ SLA** | ผู้แจ้ง |
| Task | — (ไม่มีในข้อมูล) | กำหนดส่ง | ผู้สั่งงาน |

- **Incident ใช้ SLADue ไม่ใช่ IncidentDate** — เส้นตายคือ SLA ไม่ใช่วันที่เกิดเหตุ
- **Task เก็บสถานะเป็น yes/no** (`IsCompleted`) แปลงเป็น `In Progress` / `Completed`
  เพื่อให้ตัวกรองชุดเดียวใช้ได้ทั้งสามชนิด
- คอลัมน์ **โครงการ** โผล่เฉพาะ Incident/Task (Ticket ผูกโครงการหรือไม่ก็ได้)
- ป้าย **"รอรับงาน"** บนหัวข้อ = มอบหมายแล้วแต่ยังไม่มีใครกดรับ

## ตัวเลขสรุป

`Open · In Progress · ยังไม่มีผู้รับผิดชอบ · เสร็จแล้ว`

เปลี่ยนจากเดิมที่มี **Pending** เพราะ Pending มีเฉพาะ Ticket ตัวเลขจึงเทียบข้ามชนิดไม่ได้
ส่วน **"ยังไม่มีผู้รับผิดชอบ"** มีได้ทั้งสามชนิด และเป็นสิ่งที่ต้องลงมือจริง ๆ

## ตัวกรอง

ค้นหาครอบคลุม **หัวข้อ / เลขที่ / ชื่อโครงการ / ผู้รับผิดชอบ / ผู้แจ้ง**
ตัวเลือกสถานะกับ Priority **สร้างจากข้อมูลจริงของแท็บนั้น** — ไม่เสนอตัวเลือกที่เลือกแล้วว่างเปล่า
มีติ๊ก "ซ่อนงานที่จบแล้ว" เพิ่ม

## Assign ได้ทั้งสามชนิด

| ชนิด | ผลข้างเคียง |
|---|---|
| Ticket | Open → In Progress อัตโนมัติ (เหมือนเดิม) |
| **Incident** | **ส่งเมล `incident_assigned`** + ตั้ง `IsAcknowledged = false` |
| Task | ตั้ง `IsAcknowledged = false` |

Incident ส่งเมลเพราะ**หน้า Incident ก็ส่ง** — ถ้าที่นี่เงียบ การกระทำเดียวกัน
จากสองหน้าจะให้ผลต่างกัน และคนที่ถูกมอบหมายจะไม่รู้ตัว
ใช้ `incidentMailPlan` ตัวเดียวกัน ผู้รับจึงไม่เพี้ยน

Ticket กับ Task **ไม่ส่งเมล** เพราะทางเดิมก็ไม่ส่ง — หน้านี้ไม่ใช่ที่ที่ควรเปลี่ยนกฎนั้นเงียบ ๆ

ตั้ง `IsAcknowledged = false` เพื่อให้งานไปรอในกล่อง **"รอรับงาน"** ตามระบบที่มีอยู่
ไม่งั้นงานที่มอบหมายจากหน้านี้จะโผล่ในรายการงานของเขาทันทีโดยไม่ผ่านการกดรับ

## โค้ด

ตรรกะทั้งหมดอยู่ใน [`src/utils/dashboardWork.ts`](../src/utils/dashboardWork.ts) (44 เทสต์) —
แปลงทั้งสามชนิดเป็น `WorkRow` รูปเดียวกันก่อน แล้วค่อยกรอง/นับ
ถ้าไม่ทำแบบนี้ต้องเขียนตรรกะกรองสามชุดที่เพี้ยนจากกันได้

`PM_Incidents` / `PM_Tasks` โหลดแบบ `.catch(() => {})` — ที่ติดตั้งไหนยังไม่มีลิสต์
แท็บนั้นจะว่าง แต่หน้าไม่ล้ม

## ข้อจำกัด

**Task ยังไม่มีหน้าของตัวเอง** — คลิกแล้วเปิดที่โครงการแทน (มีข้อความบอกใต้ตาราง)
ดีกว่าลิงก์ที่กดแล้วไม่มีอะไร
