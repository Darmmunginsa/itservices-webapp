# ลูกค้าของโครงการถูกเลือกไว้ก่อน ตอนสร้างงานจากในโครงการ

## ปัญหา

สร้าง Ticket / Task / Incident จากในโครงการ ต้องกดเลือกลูกค้าเข้า "ผู้เข้าร่วมลูกค้า" เองทุกครั้ง
ทั้งที่งานในโครงการเกือบทั้งหมดก็เกี่ยวกับลูกค้าชุดเดิม — และคนที่ลืมกด ลูกค้าก็ไม่ได้รับนัด

## ตอนนี้

ลูกค้าที่ผูกกับโครงการ (`PM_ProjectCustomers`) **ถูกเลือกไว้ให้ก่อน** จะเอาออกก็ค่อยตัด

| ทาง | เกิดเมื่อ |
|---|---|
| หน้าแจ้งงาน มาจากปุ่มในโครงการ (`/submit?project=ID`) | โหลดเสร็จ → เลือกไว้ทันที (ทั้ง Ticket / Task / Incident) |
| หน้าแจ้งงาน เปลี่ยนโครงการเอง | **แทนที่ทั้งชุด** ด้วยลูกค้าของโครงการใหม่ — ไม่เติมทับ ไม่งั้นสลับไปมาแล้วลูกค้าโครงการก่อนติดมาด้วย |
| หน้าโครงการ → เพิ่ม Task | เปิดโมดัล → เลือกไว้ทันที |

ตัวเลือกลูกค้าในหน้าโครงการรวม**ผู้ติดต่อในโครงการ**ด้วยแล้ว (เดิมมีแต่จากสัญญา) —
ไม่งั้นคนที่ถูกเลือกไว้ให้จะเห็นเป็นอีเมลลอย ๆ ไม่มีชื่อ

ตัดซ้ำแบบไม่สนตัวพิมพ์ และตัดแถวที่อีเมลว่าง/ผิดรูป — `presetCustomerEmails` ใน
[`src/utils/customerGroups.ts`](../src/utils/customerGroups.ts) (3 เทสต์)

## ที่ตั้งใจไม่ทำ

**Incident ในหน้าโครงการ** ไม่มีช่องผู้เข้าร่วม/ปฏิทินอยู่แล้ว จึงไม่มีอะไรให้เลือกไว้ —
ถ้าจะให้ Incident จากหน้าโครงการมีปฏิทินเหมือนหน้าแจ้งงาน เป็นอีกงาน

## ไม่ต้องแก้อะไรใน SharePoint

ใช้ `PM_ProjectCustomers` ที่มีอยู่ · ยังไม่ได้สร้างลิสต์ก็ไม่พัง แค่ไม่มีใครมารอไว้
