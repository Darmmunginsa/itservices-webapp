# งานที่ฉันแจ้ง / มอบหมายไป (หน้า My Tracking)

## ปัญหา

มอบหมายงานให้ทีมแล้ว **ถ้าไม่ได้กด Track ไว้ก็ไม่เห็นความคืบหน้าเลย** ต้องไปเปิดทีละใบ
คนสั่งงานจึงไม่รู้ว่าปลายทางรับแล้วหรือยัง เดินถึงไหน — ทั้งที่ระบบรู้อยู่แล้วว่าใครสร้างแถวไหน

## ที่เพิ่ม

หน้า My Tracking มีสองส่วน:

1. **งานที่ฉันแจ้ง / มอบหมายไป** — สร้างจากข้อมูลจริง (ผู้สร้างแถว = ฉัน) ไม่ต้องกด Track
2. **รายการที่ติดตามเอง** — ของเดิม (`HD_Tracking`)

### ป้ายความคืบหน้าหนึ่งคำ

| ป้าย | หมายถึง |
|---|---|
| 🟠 ยังไม่มีผู้รับผิดชอบ | สร้างไว้แต่ยังไม่ได้ assign ใคร — สิ่งที่ต้องตามมากที่สุด |
| 🟡 รอรับงาน | มอบหมายแล้ว แต่ปลายทางยังไม่กดรับ |
| 🔵 กำลังทำ | รับแล้ว |
| 🟢 เสร็จแล้ว | Resolved / Closed / Completed |

ตัวเลขสรุปทั้ง 4 ขึ้นบนหัวส่วน — อ่านทีเดียวรู้ว่างานที่สั่งไปค้างที่ขั้นไหนกี่ชิ้น

### กติกา

- **นับเฉพาะงานที่ฉันสร้างและมอบหมายให้คนอื่น** — งานที่ให้ตัวเองอยู่ในหน้างานของฉันแล้ว นับซ้ำจะผิด
- งานที่ **ยังไม่มีผู้รับผิดชอบนับ** — นั่นคือสิ่งที่ต้องตาม
- "คนแจ้ง" คือ **คนสร้างแถว** ไม่ใช่ลูกค้าในช่อง CustomerEmail — หัวหน้าแจ้งแทนลูกค้าก็ยังเป็นงานที่หัวหน้าแจ้ง
- เรียง: **ค้าง (ยังไม่มีคนรับ / ยังไม่กดรับ) ขึ้นก่อน** แล้วเรียงตามที่เพิ่งขยับ — คนสั่งงานอยากรู้ว่า "ค้างที่ใคร" ก่อน
- ซ่อนที่เสร็จแล้วเป็นค่าเริ่มต้น กรองตามชนิดได้

### ทำไมกรองฝั่งเบราว์เซอร์

SharePoint กรอง `Author/EMail eq` ตรง ๆ ไม่ได้ จึงดึง 500 แถวล่าสุดต่อลิสต์ (พร้อม `$expand=Author`)
แล้วคัดด้วยอีเมลผู้สร้าง — พอสำหรับงานที่ยังเดินอยู่ งานเก่ากว่านั้นจบไปแล้วเกือบทั้งหมด

ครอบคลุม Ticket / Incident / Task ทั้งสาม ผ่าน `ticketRows/incidentRows/taskRows` ตัวเดียวกับ Agent Dashboard
(เพิ่ม `requesterEmail` ให้ `WorkRow`)
