# พื้นที่ทำงานของ Incident

Incident มีหน้าของตัวเองแล้ว — `/#/incidents/:id` โครงเดียวกับ Ticket

เดิมแก้ Incident ได้แต่ในโมดัลบนหน้าโครงการ ซึ่งหมายความว่า:

- **ไม่มีที่คุยกัน** — เคสที่ยืดเยื้อไม่มีที่บันทึกว่าลองอะไรไปแล้ว
- **แนบไฟล์เพิ่มระหว่างทางไม่ได้** — มีแต่ไฟล์ที่แนบตอนเปิดเคส
- **ส่งลิงก์ให้ใครดูเฉพาะเคสนั้นไม่ได้** — ได้แค่ลิงก์หน้าโครงการแล้วบอกให้ไปไล่หา

ทั้งที่ลักษณะงานเหมือน Ticket แทบทุกอย่าง ต่างกันแค่ **Ticket คือคำขอ · Incident คือปัญหาที่มีเส้นตาย**

## ⚠️ ลิสต์ที่ต้องสร้าง — `PM_IncidentComments`

| คอลัมน์ | ชนิด |
|---|---|
| `Title` | Single line of text |
| `IncidentID` | **Number** |
| `CommentText` | **Multiple lines of text (plain)** |
| `CommentType` | Choice — `Internal`, `External` |
| `CommentDate` | Date and Time (**Include Time**) |
| `LikedBy` | Multiple lines of text |
| `ParentID` | Number |

**เปิด Attachments ของลิสต์นี้ด้วย** (List settings → Advanced settings → Attachments = Enabled)

> ยังไม่สร้าง = **หน้าเคสใช้ได้ปกติ** แค่ฝั่งขวาจะบอกว่ายังไม่ได้สร้างลิสต์
> ส่วนอื่นทั้งหมด (สถานะ · SLA · มอบหมาย · แนบไฟล์ · ปิดเคส · เมล) ทำงานเลย

## ทำอะไรได้ในหน้านี้

| ส่วน | รายละเอียด |
|---|---|
| **นาฬิกา SLA** | นับถอยหลังตัวใหญ่บนสุด · เหลือน้อยกว่า 2 ชม. เปลี่ยนเป็นสีเลยกำหนด |
| **เปลี่ยนสถานะ** | Open / In Progress / Resolved · ปิดแล้วประทับเวลาปิดให้เอง |
| **ปิดเคส** | ช่องวิธีแก้ไข + เลือกข้อความสำเร็จรูป + แนบลิงก์บทความ (เหมือน Ticket) |
| **แก้ SLA** | ปรับได้ระหว่างทาง เพราะความรุนแรงที่ประเมินตอนแรกอาจเปลี่ยน |
| **มอบหมาย** | เลือก Agent → ส่งเมล `incident_assigned` |
| **แก้ไขเนื้อเคส** | ชื่อ / ความรุนแรง / วันที่ / รายละเอียด (Agent ขึ้นไป) |
| **ลบเคส** | Boss / Admin เท่านั้น |
| **ไฟล์แนบ** | เพิ่ม/ลบได้ตลอดอายุเคส · รูปขึ้นเป็นภาพย่อ |
| **คอมเมนต์** | @mention · ไลก์ · ตอบซ้อน · แนบไฟล์ — ตัวเดียวกับที่โครงการใช้ |
| **Pin** | เข้า Focus Items |

**ปิดเคสจากหน้านี้ก็ได้พลุ** และส่งเมล `incident_resolved` เหมือนทางอื่น

## ทางเข้าที่ชี้มาหน้านี้แล้ว

| จาก | เดิมไปไหน |
|---|---|
| หน้าหลัก → งานที่ถึงกำหนด | หน้าโครงการ แล้วต้องไล่หาเคสเอง |
| หน้าโครงการ → การ์ด Incident | โมดัลรายละเอียด |
| หน้าโครงการ → กล่องงานค้าง | สลับไปแท็บ Incidents |
| งานของฉัน → การ์ด / ตาราง | หน้าโครงการ (เคสไม่มีโครงการ **กดไม่ได้เลย**) |
| Focus Items (หน้าหลัก + แถบลอย) | หน้าโครงการ |

**ปุ่มย้อนกลับพากลับที่เดิม** พร้อมชื่อที่ถูกต้อง เหมือนที่ทำกับ Ticket

## ⚠️ Focus Items ที่ pin ไว้ก่อนหน้านี้

เดิม Incident ที่ pin เก็บ **id ของโครงการ** เพราะลิงก์พาไปหน้าโครงการ
ตอนนี้เก็บ **id ของเคส** เพื่อพาเข้าเคสตรง ๆ

**รายการที่ pin ไว้ก่อนอัปเดตจะพาไปเคสผิดตัวหรือขึ้น "ไม่พบ Incident นี้"** —
เอาออกแล้ว pin ใหม่ครั้งเดียวจบ ผมไม่ได้แปลงข้อมูลเก่าให้เพราะแยกไม่ออกว่า
แถวไหนเก็บ id อะไรไว้

## หน้า Ticket ใช้โครงเดียวกันแล้ว

หลังจากใช้หน้า Incident แล้วชอบ เลยยกโครงเดียวกันไปใช้กับ Ticket ด้วย:

- **งานอยู่ซ้าย · คอมเมนต์อยู่ขวาแบ่งครึ่ง** ติดหนึบด้านบน เลื่อนในตัวเอง
- **เครื่องมือจัดการอยู่ในหน้าเลย** — เดิมซ่อนอยู่หลัง**ปุ่มลอยมุมขวาล่าง**
  ที่ต้องกดเปิดลิ้นชักก่อนจึงจะเปลี่ยนสถานะ / ปิดงาน / เชิญคนเข้าทีม / แนบไฟล์ได้
  ซึ่งเป็นเครื่องมือที่ใช้บ่อยที่สุดในหน้านั้น
- จอแคบกว่า `lg` เรียงลงล่างเหมือนกัน

ทั้งสองหน้าใช้ class ชุดเดียวกัน — แก้โครงที่เดียวขยับพร้อมกันทั้งคู่

### ปิดงานแล้วเด้งกลับให้เลย

กด **Resolved / Closed** สำเร็จ → พลุขึ้น → **~1.4 วินาทีแล้วพากลับหน้าที่มา**
(ปลายทางเดียวกับปุ่มย้อนกลับ) เพราะปิดงานแล้วไม่มีอะไรให้ทำต่อในหน้านั้น

- หน่วงไว้ให้ทันเห็นว่า "สำเร็จ" ก่อน — พลุอยู่ระดับแอป จึงเล่นต่อที่หน้าปลายทางเอง
- **เด้งเฉพาะตอนเพิ่งปิดจริง** — กดบันทึกซ้ำบนงานที่ปิดไปแล้วไม่เด้ง
- **ถ้าเปลี่ยนหน้าเองก่อนครบ 1.4 วิ จะยกเลิกให้** ไม่โดนดึงกลับมาแบบไม่รู้ตัว

**ที่ยังต่างกันโดยตั้งใจ:** Ticket มี **ทีมงานในเคส** (เชิญคนเข้ามาช่วย) ส่วน Incident
ยังไม่มี · Incident มี **นาฬิกา SLA** ส่วน Ticket ไม่มี เพราะ SLA วัดที่ Incident เท่านั้น

## ที่ย้ายออกจากหน้าโครงการ

โมดูลรายละเอียด/แก้ไข/ลบ Incident ถูกย้ายมาหน้านี้ทั้งหมด — หน้าโครงการเหลือแค่
**"แจ้ง Incident"** สำหรับเปิดเคสใหม่ ส่วน Task และ Note ยังใช้โมดัลเหมือนเดิม
