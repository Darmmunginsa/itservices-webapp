# รายงาน PM ในแอป — แคปรูปวางลง template แล้วออกเป็น PDF

**งานของฉัน → รายงาน PM** (`/pm-report`) — Agent ขึ้นไป

แทนที่จะทำรายงาน PM ด้วยมือใน Word ทีละหน้า: เปิดงาน → แคปรูปวางลงช่องของแต่ละรายการตรวจ →
ติ๊ก Pass/Fail/N/A → เขียนข้อเสนอแนะ → กด **พิมพ์ / บันทึก PDF**

```
เลือก template (ร่างไว้ล่วงหน้า)
        │
        ▼
เปิดงานใหม่ ──► แคปรูป (Ctrl+V) · ติ๊กผล · เขียนข้อเสนอแนะ
        │         └─ เก็บใน SharePoint ทันที (รูป = ไฟล์แนบของงาน)
        ▼
กดพิมพ์ ──► PDF พร้อมปก / Version History / Inventory / Check List / Figure เรียงเลข
```

**งานอยู่บน SharePoint ไม่ใช่ในเบราว์เซอร์** — ปิดเครื่องแล้วเปิดต่อได้ คนอื่นเปิดต่อได้ ไม่หาย

---

## ลิสต์ที่ต้องสร้างใน SharePoint

### `PM_ReportTemplates`

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | ชื่อ template |
| `Structure` | **Multiple lines of text (plain)** | JSON โครงรายงาน (ดูหัวข้อถัดไป) |
| `IsActive` | Yes/No | ปิดไม่ให้เลือกได้โดยไม่ต้องลบ |

### `PM_ReportJobs`

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | ชื่องาน |
| `TemplateID` | **Number** | Id ของ template ที่ใช้ |
| `Customer` | Single line of text | ระบบเขียนให้จากหัวรายงาน |
| `PMDate` | Single line of text | **Text ไม่ใช่ Date** — รับรูปแบบวันที่แบบไหนก็ได้ |
| `JobStatus` | Single line of text | `Draft` / อื่น ๆ |
| `Data` | **Multiple lines of text (plain)** | ผลตรวจ + คำบรรยาย + ข้อเสนอแนะ เก็บเป็น JSON |

**และเปิด `PM_ReportJobs` → List settings → Advanced settings → Attachments = Enabled**
(รูปทั้งหมดของงานเก็บเป็นไฟล์แนบของงานนั้น)

> ⚠️ คอลัมน์ `Data` ควรตั้งเป็น **plain text** และเช็คว่ารับความยาวได้พอ
> งานที่มี 11 อุปกรณ์ × 10 รายการ + คำบรรยายรูป อยู่ราว 5–15 KB

## รูปแบบ JSON ของ template

สร้างได้ 2 แบบ — กดสลับได้ในหน้าเดียวกัน:

### แบบ "กรอกฟอร์ม" (ค่าเริ่มต้น — ไม่ต้องเขียน JSON)

**สร้าง Template** → กรอกชื่อรายงาน → **เพิ่มอุปกรณ์** → กางอุปกรณ์แล้ว **เพิ่มรายการตรวจ**

ตัวช่วยที่ทำให้ไม่ต้องพิมพ์ซ้ำ:

| ปุ่ม | ทำอะไร |
|---|---|
| **วางหลายรายการ** | วางข้อความบรรทัดละ 1 รายการ — ตัด `1.` `02)` `-` ที่ก็อปมาจาก Word ให้เอง |
| **คัดลอกรายการจากอุปกรณ์ก่อนหน้า** | เครื่องรุ่นเดียวกันหลายตัว ใช้รายการตรวจชุดเดิม |
| **วางหลายแถว** (Inventory) | บรรทัดละ `serial, role` |
| ▲ ▼ | สลับลำดับอุปกรณ์และรายการตรวจ (เลขไล่ใหม่ให้อัตโนมัติ) |
| **ทำสำเนา** | ลูกค้ารายใหม่ที่โครงคล้ายเดิม — copy แล้วแก้ชื่ออุปกรณ์ |

### แบบ "JSON" (สำหรับของที่มีอยู่แล้ว)

**ใช้ไฟล์ `config/*.json` ของเครื่องมือ PM Report เดิมได้ตรง ๆ** — เปิดไฟล์นั้น copy ทั้งไฟล์ มาวาง

สลับกลับไปโหมดฟอร์มได้ ที่วางมาจะกลายเป็นฟอร์มให้แก้ต่อ และในทางกลับกัน
template ที่สร้างจากฟอร์มก็ดูเป็น JSON ได้ (เอาไปใช้กับเครื่องมือเดิมได้)

โครงที่ต้องมี:

```json
{
  "title": "Preventive Maintenance",
  "meta":    { "customer": "", "site": "", "pm_date": "", "engineer": "", "so_number": "" },
  "version_history": [
    { "version": "1.0", "date": "30-September-2025", "change": "Initial Document", "author": "Darm Munginsa" }
  ],
  "inventory": [
    { "no": "01", "serial": "SGH123W04V", "role": "HPE DL380 Gen10 (VMware ESX)" }
  ],
  "devices": [
    {
      "key": "srv1",
      "name": "HPE DL380 Gen10 - VMware ESX - (SGH123W04V)",
      "tasks": [
        { "no": "01", "name": "Checking event logs for Critical and Major events" },
        { "no": "02", "name": "Checking LED/LCD displays for error indications" }
      ]
    }
  ]
}
```

**บังคับแค่ `devices`** ที่เหลือขาดได้:

| ขาดอะไร | ระบบทำอะไรให้ |
|---|---|
| `key` ของอุปกรณ์ | ใช้ชื่ออุปกรณ์แทน (ซ้ำกันจะถูกแยกให้อัตโนมัติ) |
| `no` ของ task | ไล่เลข `01`, `02`, ... ให้ |
| `name` ของ task | ใช้ `label` ถ้ามี |
| `title` | ใช้ชื่อจาก `template` (ตัด `.docx` ออก) |

ถ้า JSON ใช้ไม่ได้ ช่องกรอกจะบอกเหตุผลเป็นภาษาคนก่อนบันทึก และถ้าอ่านได้จะขึ้นสรุปให้ว่า
**"อ่านได้: 11 อุปกรณ์ · 33 รายการตรวจ · inventory 14 แถว"** — เห็นก่อนว่าตรงกับที่ตั้งใจไหม

> `key` ของอุปกรณ์คือที่อยู่ของรูปและผลตรวจ ตัวสร้างฟอร์มจะตั้งเป็น `dev-1`, `dev-2`, ...
> **ไม่ผูกกับชื่อ** — เปลี่ยนชื่ออุปกรณ์ทีหลังได้ รูปของงานเก่าไม่หาย
>
> แต่ **การลบหรือสลับลำดับรายการตรวจ** ของ template ที่มีงานทำอยู่แล้ว จะทำให้เลข task เปลี่ยน
> และรูปของงานเก่าหาที่อยู่ไม่เจอ — หน้าจอเตือนไว้แล้ว ถ้าจะรื้อโครงใหญ่ให้กด **ทำสำเนา** แล้วแก้ในสำเนา

## วิธีแคปรูป

1. `Win + Shift + S` แคปหน้าจอ (เหมือนเดิม)
2. **กดที่กรอบวางรูปของรายการนั้น** — กรอบเปลี่ยนเป็นสีน้ำเงิน = พร้อมรับ
3. กด `Ctrl + V`

- วางได้หลายรูปต่อ 1 รายการ
- **ลากไฟล์รูปมาวาง**ก็ได้ หรือกด **เลือกไฟล์**
- รูปถูก**ย่อให้กว้างไม่เกิน 1600 px** ก่อนอัปโหลด (เท่าเครื่องมือเดิม)
- **อัปโหลดทันทีทีละภาพ** — เบราว์เซอร์ปิดกลางทาง ภาพที่ขึ้นไปแล้วไม่หาย

**ต้องกดเลือกช่องก่อนวางเสมอ** ตั้งใจให้เป็นแบบนี้ — ถ้ารับ Ctrl+V ทุกที่ จะวางรูปผิดช่องโดยไม่รู้ตัว
ซึ่งกว่าจะรู้คือตอนเปิด PDF แล้ว

## บันทึกงาน

- **บันทึกอัตโนมัติ** ทุก 4 วินาทีหลังหยุดแก้ + มีปุ่มบันทึกเอง
- แถบบนบอกสถานะ: `ยังไม่บันทึก` / `กำลังบันทึก...` / `บันทึกแล้ว`

## ตรวจก่อนพิมพ์

กล่องเหลืองบอกสิ่งที่ยังขาด **แต่ไม่บล็อกการพิมพ์** (บางรายงานไม่ต้องมีรูปทุกอุปกรณ์จริง ๆ):

- หัวรายงานช่องไหนยังว่าง
- ยังไม่ติ๊กผลกี่รายการ
- อุปกรณ์ไหนยังไม่มีรูปเลย
- Inventory ยังไม่เลือกสถานะกี่แถว
- อุปกรณ์ไหนยังไม่เขียนข้อเสนอแนะ

## ผลลัพธ์ PDF

กด **พิมพ์ / บันทึก PDF** → เลือก **Save as PDF** ในหน้าต่างพิมพ์ของเบราว์เซอร์

- **ปก** — ชื่อรายงาน · ลูกค้า · สถานที่ · วันที่ · วิศวกร · เลข SO
- **Version History** / **Inventory** (มี Report Status) — ขึ้นหน้าใหม่
- **ทีละอุปกรณ์ ขึ้นหน้าใหม่ทุกตัว** — Check List (✅/❌/N/A) → รูป → Recommendations
- **Figure เรียงเลขต่อกันทั้งเอกสาร** ไม่รีเซ็ตตามอุปกรณ์
- ธีมมืดถูกถอดชั่วคราวตอนพิมพ์ ไม่ได้พื้นดำกินหมึก

## สิทธิ์

| ทำอะไร | ใคร |
|---|---|
| สร้าง / ทำ / พิมพ์รายงาน | Agent ขึ้นไป |
| เพิ่ม template | Supervisor ขึ้นไป |

## ต่างจากเครื่องมือเดิมอย่างไร

| | เครื่องมือเดิม (PM Report) | ในแอปนี้ |
|---|---|---|
| ต้องลง Python | ✅ ทุกเครื่อง | ❌ ไม่ต้อง |
| ผลลัพธ์ | Word ตาม template เดิม | **PDF** |
| งานเก็บที่ไหน | เบราว์เซอร์เครื่องนั้น | **SharePoint** — เปิดต่อ/ส่งต่อได้ |
| ทำงานร่วมกัน | ไม่ได้ | ได้ (คนละเวลา) |

**ถ้าลูกค้ารายไหนบังคับเป็นไฟล์ Word ตาม template เดิม** ให้ใช้เครื่องมือเดิมกับรายนั้นต่อไป —
ในแอปนี้ออกเป็น PDF เท่านั้น
