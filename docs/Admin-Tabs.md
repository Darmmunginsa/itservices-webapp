# หน้า Admin แบ่งเป็นแท็บ

เดิม 7 หมวดอยู่หน้าเดียวยาว ต้องเลื่อนหาทุกครั้ง — ตอนนี้แต่ละหมวดเป็นแท็บของตัวเอง

| แท็บ | จัดการ |
|---|---|
| 📢 ข้อความวิ่ง | `HD_Announcements` |
| 📅 วันหยุด | `HD_Holidays` |
| ✅ ผู้อนุมัติการลา | `HD_AgentProfiles.ApproverEmail` |
| 🧮 โควต้าวันลา | `HD_LeaveQuota` |
| ✉️ Template อีเมล | `HD_EmailTemplates` + บัญชีผู้ส่ง (`HD_Options`) |
| ▶️ วิดีโอหน้าหลัก | `HD_Options` |
| 🔐 สิทธิ์เข้าหน้า | `HD_PagePermissions` |

## แท็บอยู่ใน URL

`#/admin?tab=templates` — รีเฟรชแล้วอยู่หมวดเดิม และ**ส่งลิงก์ตรงหมวดได้**
(เช่นจากหน้า Diagnostic ที่บอกว่า template ตัวไหนมีปัญหา) · ค่าที่ไม่รู้จักถอยไปแท็บแรก

## วิธีทำ

ไม่ได้แยกไฟล์ — ครอบแต่ละ `<Card>` ด้วย `{tab === 'x' && (…)}` เท่านั้น
state, ตัวโหลดข้อมูล และ modal ทั้งหมดอยู่ที่เดิม จึงไม่มีอะไรเปลี่ยนพฤติกรรม แค่แสดงทีละหมวด
