# โน้ต & แหล่งอ้างอิง — แนบไฟล์ในเนื้อหา และแชร์โน้ต

## 1. แทรกไฟล์/รูปกลางเนื้อหา

ใช้ได้ทั้ง **Tools & Notes** และ **แหล่งอ้างอิง** — เขียน `[[ชื่อไฟล์]]` ตรงจุดที่อยากให้รูปโผล่:

```
## ขั้นตอนต่อสาย
1. ถอดฝาหน้าออก
[[panel-front.png]]

2. เสียบสาย console ตามผัง
[[wiring.pdf]]
```

- **รูป** (png jpg gif webp bmp svg) แสดงตรงนั้นเลย กดขยายดูเต็มจอได้
- **ไฟล์อื่น** เป็นปุ่มดาวน์โหลดพร้อมชื่อไฟล์จริง
- ไฟล์ต้องถูก **แนบกับรายการนั้น** ก่อน (ปุ่มแนบไฟล์ในหน้าแก้ไข)
- ในหน้าแก้ไขมีปุ่ม **+ ชื่อไฟล์** กดแล้วแทรกให้ท้ายเนื้อหา ไม่ต้องพิมพ์เอง
- พิมพ์ชื่อผิดหรือลบไฟล์ทิ้ง จะขึ้น **⚠ ไม่พบไฟล์แนบ "…"** ตรงตำแหน่งนั้น
  และในหน้าแก้ไขจะเตือนก่อนบันทึกว่าอ้างถึงไฟล์ที่ยังไม่ได้แนบ

> แนบไฟล์ได้**หลังบันทึกครั้งแรก** เพราะ SharePoint ต้องมี id ของรายการก่อนจึงแนบไฟล์ได้

โน้ตใน Tools ตอนนี้ใช้รูปแบบเดียวกับแหล่งอ้างอิงแล้ว — `## หัวข้อ`, `- รายการ`, URL กดได้, และ `[[ไฟล์]]`

## 2. แชร์โน้ตให้บางคนในทีม

หน้าแก้ไขโน้ต → **แชร์ให้ (เห็นอย่างเดียว)** → เลือกชื่อจากทีม

| ใคร | ทำอะไรได้ |
|---|---|
| เจ้าของโน้ต | แก้ไข / ลบ / แนบไฟล์ / เปลี่ยนคนที่แชร์ให้ |
| คนที่ถูกแชร์ให้ | เปิดอ่าน + ดาวน์โหลดไฟล์แนบ **เท่านั้น** |
| คนอื่น | ไม่เห็นโน้ตนั้นเลย |

โน้ตที่คนอื่นแชร์มาจะขึ้นในหน้า Tools พร้อมป้าย **"แชร์มาให้"** (เอาเมาส์ชี้เห็นว่าใครเป็นเจ้าของ)
โน้ตของเราที่แชร์ออกไปจะมีป้าย **🔗 แชร์ N**

### ⚠️ ข้อจำกัดที่ต้องรู้

**การแชร์นี้คุมที่หน้าจอเท่านั้น ไม่ใช่สิทธิ์จริงของ SharePoint**

ใครก็ตามที่เปิดลิสต์ `IT_Tools` ใน SharePoint ตรง ๆ จะเห็นโน้ตทุกใบของทุกคน
**อย่าเก็บรหัสผ่านหรือความลับไว้ในโน้ต** — ถ้าต้องการกันจริงต้องตั้ง item-level permission ใน SharePoint ซึ่งแอปทำแทนไม่ได้

(หน้าจอเตือนเรื่องนี้ไว้ใต้ช่องแชร์แล้ว)

## คอลัมน์ที่ต้องเพิ่มใน SharePoint

### `IT_Tools`

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `SharedWith` | Multiple lines of text (plain) | อีเมลคั่นด้วย `,` — ระบบเขียนให้เอง ไม่ต้องกรอกมือ |

และเปิด **List settings → Advanced settings → Attachments = Enabled**

### `PM_References`

เปิด **Attachments = Enabled** (ถ้ายังไม่ได้เปิดตอนตั้งค่าครั้งแรก)

> ถ้ายังไม่เพิ่ม `SharedWith` — โน้ตยังใช้ได้ปกติ แค่แชร์ไม่ได้ (เลือกแล้วไม่ถูกบันทึก)
> ถ้ายังไม่เปิด Attachments — ช่องแนบไฟล์จะขึ้นว่าโหลดไม่สำเร็จ ส่วนอื่นทำงานปกติ
