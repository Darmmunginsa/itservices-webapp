# อีเมลแจ้งเตือน Incident

Incident เคย**ไม่ส่งอีเมลเลยสักจังหวะ** — มีแต่แจ้งเตือนในแอป ซึ่งคนเห็นก็ต่อเมื่อ
เปิดแอปอยู่ ทั้งที่ Incident คือเรื่องเร่งด่วนที่รอให้คนบังเอิญเข้าแอปไม่ได้

ตอนนี้ส่งครบ 3 จังหวะ

| จังหวะ | EventKey | ส่งเมื่อ |
|---|---|---|
| เปิดเคส | `incident_created` | สร้าง Incident ใหม่ |
| มอบหมาย | `incident_assigned` | **เปลี่ยน**ผู้รับผิดชอบ |
| ปิดเคส | `incident_resolved` | สถานะ**เพิ่งเปลี่ยน**เป็น Resolved |

ครอบคลุมทั้ง 3 ทางที่สร้าง Incident ได้: **หน้าโครงการ · หน้าแจ้งงาน · Add-in**

---

## ⚠️ ต้องเพิ่ม 3 แถวใน `HD_EmailTemplates`

| คอลัมน์ | ค่า |
|---|---|
| `Title` | ชื่ออะไรก็ได้ เช่น "Incident เปิดเคส" |
| `EventKey` | `incident_created` / `incident_assigned` / `incident_resolved` |
| `Subject` | ใส่อะไรก็ได้ — **ระบบเขียนทับเป็น `[Incident] ชื่อเคส`** (ดูหัวข้อ "เธรด") |
| `Body` | HTML ใส่ตัวแปรได้ |
| `IsEnabled` | Yes |

> **ยังไม่เพิ่ม = บันทึกได้ตามปกติ แต่เมลไม่ออก** และหน้าจอจะขึ้นเตือนว่า
> *"ยังไม่ได้เปิด template ..."* พร้อมชื่อ EventKey — ไม่เงียบเหมือนเดิม

## ตัวแปรที่ใช้ได้

| ตัวแปร | ค่า |
|---|---|
| `{{incident_title}}` | ชื่อเคส |
| `{{severity}}` | Critical / High / Medium / Low |
| `{{status}}` | สถานะปัจจุบัน |
| `{{description}}` | รายละเอียด |
| `{{resolution}}` | วิธีแก้ (ใช้ตอนปิดเคส) |
| `{{incident_date}}` | วันที่เกิดเหตุ |
| `{{sla_hours}}` | เช่น `4 ชั่วโมง` หรือ `1 วัน` · ไม่ได้ตั้ง SLA = ว่าง |
| `{{project_name}}` | ชื่อโครงการ |
| `{{assigned_name}}` | ผู้รับผิดชอบ · ไม่มี = `-` |
| `{{link}}` | ลิงก์เปิดโครงการในระบบ |

**ทุกตัวแปรเป็นข้อความเสมอ** ไม่มีทางออกมาเป็น `undefined` ในเมลที่ส่งถึงลูกค้า

### ตัวอย่าง Body

```html
<p>เรียนทีมงาน</p>
<p>มีเคสที่ต้องดำเนินการ</p>
<ul>
  <li>ความรุนแรง: {{severity}}</li>
  <li>โครงการ: {{project_name}}</li>
  <li>ผู้รับผิดชอบ: {{assigned_name}}</li>
  <li>ต้องแก้ไขภายใน: {{sla_hours}}</li>
</ul>
<p>{{description}}</p>
<p><a href="{{link}}">เปิดดูในระบบ</a></p>
```

## เธรดเดียวกันทั้ง 3 ฉบับ

ระบบตั้งหัวข้อเป็น **`[Incident] ชื่อเคส`** เหมือนกันทุกฉบับ — โปรแกรมเมลจึงรวม
เปิด/มอบหมาย/ปิด ของเคสเดียวกันเป็นเธรดเดียว แทนที่จะเป็นเมลกระจัดกระจาย 3 ฉบับ

และเติม**แถบหัวเมล**ให้อัตโนมัติ — Critical/High เป็นสีแดง ที่เหลือสีเหลือง

## ใครได้รับ

| ช่อง | ใคร |
|---|---|
| **To** | ผู้รับผิดชอบ |
| **CC** | ผู้แจ้ง + เจ้าของโครงการ + สมาชิกทีม |

- **คนกดปุ่มไม่ได้รับเมลของตัวเอง** — ไม่มีประโยชน์ และทำให้คนเลิกอ่าน
- **ยังไม่มีผู้รับผิดชอบ → ผู้แจ้งเลื่อนขึ้นเป็น To** ไม่ใช่ไม่ส่งเลย
  (เมลที่มีแต่ CC ไม่มี To ส่งไม่ออก)
- อีเมลซ้ำข้ามตัวพิมพ์ใหญ่เล็กได้รับฉบับเดียว

## ส่งเฉพาะตอนเปลี่ยนจริง

| ทำอะไร | ส่งไหม |
|---|---|
| เปลี่ยนผู้รับผิดชอบเป็นคนใหม่ | ✅ |
| กดบันทึกโดยไม่เปลี่ยนผู้รับผิดชอบ | ❌ |
| ปิดเคสที่ยังเปิดอยู่ | ✅ |
| กดบันทึกเคสที่ปิดไปแล้ว | ❌ |
| เปลี่ยนสถานะเป็น In Progress | ❌ (ไม่ใช่การปิด) |

ถ้าส่งทุกครั้งที่กดบันทึก **คนจะเลิกอ่านภายในสัปดาห์เดียว** ซึ่งแย่กว่าไม่ส่ง
