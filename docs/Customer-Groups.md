# กลุ่มลูกค้าตามโครงการ

ตั้งผู้ติดต่อฝั่งลูกค้าไว้ที่โครงการครั้งเดียว แล้วตอนสร้าง **Ticket / Task**
เลือกเป็นกลุ่มได้ทีเดียวทั้งชุด

```
โครงการ #VDI → แท็บ 👥 ลูกค้า
   สมชาย  somchai@acme.co.th   ACME
   อารีย์  aree@acme.co.th      ACME
   กมล    kamol@acme.co.th     ACME
                  │
                  ▼
สร้าง Ticket → ผู้เข้าร่วม ลูกค้า
   ┌──────────────────────────┐
   │ กลุ่มตามโครงการ           │
   │ ☑ #VDI · 3 คน            │  ← กดครั้งเดียวได้ทั้งชุด
   │ ☐ #Backup · 5 คน         │
   │ ─────────────            │
   │ ☐ บริษัท ก (ACME)        │  ← เลือกทีละคนได้เหมือนเดิม
   └──────────────────────────┘
```

ทำไมถึงคุ้ม: คนฝั่งลูกค้าที่ต้องเชิญมักเป็นชุดเดิมทุกครั้ง การไล่ติ๊กทีละคนทุกรอบ
คือจังหวะที่คนตกหล่นบ่อยที่สุด และคนที่ตกหล่นคือคนที่ไม่รู้เรื่อง

---

## ⚠️ ลิสต์ที่ต้องสร้าง — `PM_ProjectCustomers`

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | ชื่อผู้ติดต่อ (ไม่ใส่ ระบบใช้อีเมลแทน) |
| `CustomerEmail` | Single line of text | **จำเป็น** |
| `ProjectID` | **Number** | ผูกกับโครงการ |
| `Company` | Single line of text | ไม่ใส่ก็ได้ |

> ยังไม่สร้างลิสต์นี้ ระบบ**ไม่พัง** — แค่ไม่มีกลุ่มให้เลือก และแท็บ 👥 ลูกค้า
> จะบอกว่ายังไม่ได้สร้าง

## จัดการที่ไหน

**โครงการ → แท็บ 👥 ลูกค้า** — เพิ่ม/ลบผู้ติดต่อ (Agent ขึ้นไป)

เพิ่มได้ 2 ทาง:

| ปุ่ม | ใช้เมื่อ |
|---|---|
| **เลือกจากทะเบียนลูกค้า** | คนนั้นมีอยู่ในหน้า ลูกค้า / Contacts แล้ว — ติ๊กได้หลายคนพร้อมกัน |
| **พิมพ์เอง** | คนที่ยังไม่มีในทะเบียน |

ทางแรกควรเป็นทางหลัก เพราะ**พิมพ์อีเมลผิดตัวเดียวก็ไม่ถึงคนรับ** และไม่มีอะไรฟ้อง

- ค้นหาจาก **ชื่อ / อีเมล / บริษัท**
- **คนที่อยู่ในโครงการแล้วจะไม่โผล่ซ้ำ** (เทียบแบบไม่สนตัวพิมพ์)
- เพิ่มทีละหลายคน ถ้ามีบางคนพลาด **จะบอกจำนวนที่พลาด** ไม่ใช่บอกว่าสำเร็จเฉย ๆ

ชื่อกลุ่มคือชื่อโครงการ ตั้งชื่อโครงการว่า `#VDI` กลุ่มก็ชื่อ `#VDI`

## พฤติกรรมตอนเลือก

| กด | เกิดอะไร |
|---|---|
| กลุ่มที่ยังไม่ได้เลือก | เพิ่มทุกคนในกลุ่ม |
| กลุ่มที่เลือกไว้บางคน | **เติมให้ครบ** ไม่เพิ่มซ้ำคนเดิม |
| กลุ่มที่เลือกครบแล้ว | เอาออกทั้งกลุ่ม |

ช่องติ๊กของกลุ่มบอกสถานะ 3 แบบ — ว่าง / `–` (บางส่วน) / `✓` (ครบ)

**เอากลุ่มออกจะไม่แตะคนที่เลือกเองนอกกลุ่ม** เพราะคนพวกนั้นตั้งใจเลือกมา

**อีเมลซ้ำจะไม่ถูกเชิญสองครั้ง** ต่อให้พิมพ์ตัวพิมพ์ใหญ่เล็กต่างกัน

## ผู้ติดต่อในโครงการโผล่ในรายชื่อรายคนด้วย

ไม่ใช่แค่ในกลุ่ม — ไม่งั้นพอเลือกกลุ่มมาแล้วจะเห็นอีเมลลอย ๆ ที่ไม่มีชื่อกำกับ
ว่าเป็นใคร ซึ่งตรวจทานก่อนส่งไม่ได้

## ข้อจำกัด

- **โครงการที่ยังไม่มีผู้ติดต่อ จะไม่โผล่เป็นกลุ่ม** — กดแล้วไม่เกิดอะไรก็ไม่ต้องมี
- กลุ่มผูกกับ**โครงการ** เท่านั้น ยังไม่มีกลุ่มแบบตั้งเองอิสระ (เช่น "ผู้บริหารทุกโครงการ")
  ถ้าต้องการ บอกได้
- คนเดียวกันอยู่ได้หลายโครงการ — เพิ่มในแต่ละโครงการแยกกัน
