# รายชื่อคนทั้งองค์กรในช่อง "ผู้เข้าร่วม Internal"

ตอนสร้าง **Ticket / Task** ช่องผู้เข้าร่วม Internal เดิมเลือกได้เฉพาะคนใน `HD_AgentProfiles`
(ทีมซัพพอร์ต) — แต่คนที่ต้องเชิญเข้าประชุมมักไม่ใช่ทีมซัพพอร์ต เช่นฝ่ายขาย บัญชี หัวหน้า

ตอนนี้ดึงรายชื่อทุกคนใน Microsoft 365 ของบริษัทมารวมด้วย

```
ผู้เข้าร่วม Internal · ทั้งองค์กร 48 คน
┌────────────────────────────────┐
│ สมชาย ใจดี · Network           │  ← ทีมซัพพอร์ตขึ้นก่อน
│ สุดา รักงาน · Helpdesk         │
│ ──────────────                 │
│ กมล ขายเก่ง · ฝ่ายขาย          │  ← คนอื่นในองค์กร เรียงตามชื่อ
│ อารีย์ บัญชี · บัญชี            │
└────────────────────────────────┘
```

**ทีมซัพพอร์ตอยู่บนสุดเสมอ** เพราะถูกเลือกบ่อยที่สุด · คนอื่นเรียงตามชื่อ
คนที่อยู่ทั้งสองที่แสดงครั้งเดียว โดยยึดข้อมูลฝั่งทีมซัพพอร์ต (มีกลุ่มงานกำกับ)

**แสดงแผนก/ตำแหน่งต่อท้ายชื่อ** เพื่อแยกคนชื่อคล้ายกัน — องค์กรที่มีคนเยอะ ชื่อซ้ำเป็นเรื่องปกติ

---

## ⚠️ ต้องเพิ่มสิทธิ์ใน App Registration

| หัวข้อ | ค่า |
|---|---|
| Permission | **`User.ReadBasic.All`** (Microsoft Graph → Delegated) |
| Admin consent | **ไม่จำเป็น** — ผู้ใช้กดยินยอมเองได้ |

**Azure Portal → App registrations → (แอป Helpdesk) → API permissions → Add a permission
→ Microsoft Graph → Delegated permissions → `User.ReadBasic.All` → Add**

> อ่านได้แค่ข้อมูลพื้นฐาน — ชื่อ อีเมล ตำแหน่ง แผนก
> เป็นสิทธิ์แบบ delegated จึงเห็นได้เท่าที่ผู้ใช้คนนั้นเห็นเองอยู่แล้วใน Outlook

## ยังไม่เพิ่มสิทธิ์ก็ใช้งานได้

ระบบ**ไม่พัง** ถ้ายังไม่ได้ตั้ง — ช่องจะแสดงเฉพาะทีมซัพพอร์ตเหมือนเดิม
พร้อมลิงก์ **"+ แสดงรายชื่อทุกคนในองค์กร"** ให้กดยินยอมครั้งเดียว

**ขอ token แยกใบจากปฏิทิน/เมลโดยตั้งใจ** — ถ้าเอาสิทธิ์นี้ไปรวมกับ scope เดิม
tenant ที่ยังไม่ได้ consent จะขอ token ไม่ผ่านทั้งชุด แล้ว**ปฏิทินกับการส่งเมลจะใช้ไม่ได้ไปด้วย**
ทั้งที่ไม่เกี่ยวกันเลย

## คนที่ไม่ขึ้นในรายชื่อ

| ไม่ขึ้น | เพราะ |
|---|---|
| Guest / บัญชี `#EXT#` | เป็นคนนอกองค์กร — ช่องนี้คือ **Internal** คนนอกมีช่องของตัวเองอยู่แล้ว |
| `noreply@` `postmaster@` ฯลฯ | บัญชีระบบ ไม่มีคนอ่าน |
| บัญชีที่ไม่มีอีเมล | เชิญไม่ได้อยู่ดี |

> **ไม่ได้กรองห้องประชุม/อุปกรณ์** เพราะปกติไม่อยู่ใน `/users` — ถ้า tenant ไหน sync
> เข้ามาด้วยจะเห็นปนอยู่ บอกได้ครับ จะกรองเพิ่ม

## ข้อจำกัด

- **เก็บไว้แค่ช่วง session** (ปิดแท็บแล้วหาย) — คนเข้า/ออกบริษัทจะได้ไม่ค้าง
  ระหว่าง session เดียวกันจะไม่เห็นคนที่เพิ่งถูกเพิ่มเข้ามา ต้องเปิดแท็บใหม่
- ดึงได้สูงสุดราว **10,000 คน** (10 หน้า × 999) — เกินกว่านั้นจะไม่ครบ
- **ช่อง "Assign ให้ Agent" ยังเป็นทีมซัพพอร์ตเท่านั้นโดยตั้งใจ** — มอบหมายงานให้คนที่ไม่ได้อยู่
  ในทีมซัพพอร์ตแล้วไม่มีใครตามงานนั้น การเชิญเข้าร่วมกับการมอบหมายงานเป็นคนละเรื่อง
