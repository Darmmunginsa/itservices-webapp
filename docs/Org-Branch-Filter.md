# ดูเฉพาะสายบังคับบัญชา (ผังองค์กร)

## ปัญหา

พอคนเยอะ ผังทั้งใบกว้างจนต้องเลื่อนซ้ายขวาหาสายที่อยากดู
การย่อกิ่งอื่นทีละกิ่งช่วยได้ แต่ต้องกดหลายครั้ง และต้องจำเองว่าย่ออะไรไว้บ้าง

## วิธีใช้

สามทางเข้า ทำสิ่งเดียวกัน:

| ทาง | ใช้เมื่อ |
|---|---|
| ช่อง **"ทุกสายบังคับบัญชา"** บน toolbar | รู้ชื่อหัวสายที่จะดู |
| ไอคอน 🜲 มุมขวาบนของการ์ด (โผล่ตอนชี้เมาส์) | เห็นคนนั้นอยู่ตรงหน้าแล้ว |
| ชื่อกลางทางใน breadcrumb | ถอยขึ้นไปดูสายที่กว้างกว่า |

ในรายการเลือก **ย่อหน้าบอกว่าใครอยู่ใต้ใคร** และ `(N)` คือจำนวนคนทั้งสาย
เสนอเฉพาะคนที่มีลูกน้อง — เลือกคนที่ไม่มีลูกน้องก็ได้ผังใบเดียว ซึ่งไม่ใช่การดูสาย

## จุดที่ตั้งใจ

- **ไม่แก้โครงสร้างข้อมูล** แค่เปลี่ยนจุดเริ่มวาด — กด "ดูทั้งองค์กร" กลับได้ทุกเมื่อ
- **breadcrumb** บอกว่าสายที่ดูอยู่ตรงไหนขององค์กร ไม่งั้นดูสายลึก ๆ แล้วหลง
- **ค้นหาข้ามสาย**: ถ้าค้นเจอคนที่อยู่นอกสายที่กำลังดู จะขึ้นปุ่มสีเหลือง
  *"อีก N คนอยู่นอกสายนี้"* — ไม่งั้นจะดูเหมือนค้นไม่เจอ ทั้งที่มีคนอยู่
- **หัวสายที่หายไป** (ลาออก / แก้ผู้อนุมัติ) กลับไปวาดทั้งใบ ดีกว่าจอว่างโดยไม่บอกอะไร
- ไม่จำค่าที่เลือกข้ามการเปิดหน้า — คนส่วนใหญ่เข้ามาดูทั้งใบก่อน

## โค้ด

ตรรกะต้นไม้ทั้งหมดอยู่ใน [`src/utils/orgBranch.ts`](../src/utils/orgBranch.ts) (มีเทสต์ 22 ข้อ)
เดิมสร้างต้นไม้ใน `OrgChart.tsx` โดยตรง ย้ายออกมาเพื่อทดสอบเคสข้อมูลวนได้

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `buildOrgTree(people, selfApprove)` | โครงต้นไม้จาก `ApproverEmail` + `parentOf` สำหรับ breadcrumb |
| `branchOptions(tree)` | รายชื่อหัวสาย พร้อมความลึกและจำนวนคนทั้งสาย |
| `subtreeSize(email, childrenOf)` | นับคนทั้งสาย (ไม่นับตัวเอง) |
| `pathToRoot(email, parentOf)` | ทางเดินจากบนสุดลงมา |
| `visibleRoots(tree, branch)` | จุดเริ่มวาด — ว่างหรือหาไม่เจอ = ทั้งใบ |

**ข้อมูลวน (A→B→A)** ทุกฟังก์ชันมี `visited` กันวนไม่จบ และคนที่เดินจากบนสุดไม่ถึง
จะถูกยกขึ้นเป็นระดับสูงสุดพร้อมป้าย "สายวน" แทนที่จะหายไปจากผังเงียบ ๆ

## ไม่ต้องแก้อะไรใน SharePoint

ใช้ `ApproverEmail` ใน `HD_AgentProfiles` ที่มีอยู่แล้ว
