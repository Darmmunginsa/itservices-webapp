# เนื้อนัดหมายในปฏิทิน (Outlook / Teams) — รูปแบบทางการ

## ปัญหา

กดสร้างนัด/ลิงก์ประชุมจากระบบ ผู้เข้าร่วมเปิดนัดแล้วเห็นแค่คำอธิบายก้อนเดียว
ไม่รู้ว่าเป็นงานประเภทไหน เลขที่อะไร ใครรับผิดชอบ กำหนดเมื่อไหร่ — ต้องเปิดระบบดูอีกที
ซึ่ง**ลูกค้าที่ถูกเชิญทำไม่ได้** เพราะเข้าระบบไม่ได้

## ตอนนี้

เนื้อนัดเป็น HTML สไตล์เดียวกับอีเมลของระบบ:

```
┌ iT ──────────────────────────────┐
│ Incident                          │  ← แถบสีตามชนิด (Incident แดง / อื่นน้ำเงิน)
│ ระบบ VDI สาขา 2 เข้าไม่ได้ทั้งสาขา  │
├───────────────────────────────────┤
│ รายละเอียด                         │
│  โครงการ      #VDI (ACME)          │
│  ผู้รับผิดชอบ  สมชาย ใจดี            │
│  ลูกค้า       คุณอารีย์ (ACME)       │
│  ความรุนแรง   Critical             │
│  ครบ SLA     12/9/69 14:00        │
│  ผู้นัด        หัวหน้าทีม            │
│ ▌ คำอธิบายหลายบรรทัด…              │
│ 🎥 ประชุมออนไลน์ผ่าน Teams          │
│ [ เปิดดูในระบบ ]                    │
└───────────────────────────────────┘
```

- **แถวที่ไม่มีค่าไม่แสดง** — ช่องว่างกลางตารางดูเหมือนระบบพัง
- Ticket ใช้คำว่า "ความสำคัญ / กำหนดส่ง" · Incident ใช้ "ความรุนแรง / ครบ SLA"
- **ข้อความทุกช่องหนีอักขระ** — เนื้อนัดเป็น HTML ที่ Outlook แสดงตรง ๆ พิมพ์ `<3` แล้วนัดเพี้ยนไม่ได้
- ไม่มีลิงก์ = ไม่มีปุ่ม (นัดส่วนตัวจากปฏิทิน)

## ใช้ที่ไหน

| ทาง | ชนิด |
|---|---|
| แจ้งงาน → Ticket / Task / Incident (ติ๊กเพิ่มใน Outlook Calendar) | ตามชนิด · ลิงก์เข้างานนั้นตรง ๆ |
| หน้าโครงการ → เพิ่ม Task | Task · ลิงก์เข้าโครงการ |
| ปฏิทิน → สร้างนัด | Task (ถ้าผูกโครงการ) หรือ "นัดหมาย" |

`createCalendarEvent` รับ `bodyHtml` เพิ่ม — ใช้ตามนั้น ไม่แปลง `\n` ซ้ำ (ของเดิม `body` ยังใช้ได้)
