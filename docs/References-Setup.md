# คลังแหล่งอ้างอิงความรู้

**ทรัพยากร → แหล่งอ้างอิง** (`/references`) คือคลังกลางขององค์กร เก็บหนังสือ มาตรฐาน RFC
เอกสารผู้ผลิต คอร์ส ฯลฯ ที่ทีมใช้อ้างอิง — เข้าไปเพิ่ม/แก้ได้ทุกเมื่อ ไม่ต้องผ่านโครงการ

หน้า **Project detail → แท็บ 📚 อ้างอิง** แค่ **ผูก** รายการจากคลังเข้ากับโครงการ แล้วเปิดอ่าน
ไม่ได้แก้เนื้อหาแหล่งอ้างอิงจากตรงนั้น

```
        คลังกลาง PM_References
        (หนังสือ 1 เล่ม มีรายการเดียว)
                 │
                 │  PM_ProjectReferences  ← ลิสต์เชื่อม
                 │  เก็บ "อ้างถึงหน้าไหน / ใช้กับเรื่องอะไร" ของแต่ละโครงการ
        ┌────────┼────────┐
     โครงการ A  โครงการ B  โครงการ C
```

**ทำไมแยกสองลิสต์:** หนังสือเล่มเดียวมักถูกใช้หลายโครงการ ถ้าเก็บซ้ำในแต่ละโครงการ
พอแก้ ISBN หรือปีที่พิมพ์ก็ต้องไล่แก้ทุกที่ และบรรณานุกรมจะมีรายการซ้ำ
ส่วน "อ้างถึงบทไหน" ต่างกันไปตามโครงการ จึงเก็บไว้ที่ลิสต์เชื่อมแทน

---

## ลิสต์ที่ 1 — `PM_References` (คลังกลาง)

SharePoint site เดียวกับ Helpdesk → **New → List** → ชื่อ **`PM_References`**

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | มีมาให้แล้ว — **ชื่อเรื่อง/ชื่อหนังสือ** |
| `RefType` | Choice | `Book, Standard, RFC, Article, Vendor doc, Video, Course, Internal, Other` |
| `Authors` | Single line of text | ผู้แต่ง / องค์กรผู้ออกมาตรฐาน |
| `Year` | Single line of text | **Text ไม่ใช่ Number** — รองรับ "2016", "n.d.", "ค.ศ. 2019" |
| `Publisher` | Single line of text | สำนักพิมพ์ / ผู้เผยแพร่ |
| `Edition` | Single line of text | ครั้งที่พิมพ์ / เวอร์ชัน เช่น `2nd ed.`, `v3.1` |
| `Identifier` | Single line of text | ISBN / DOI / เลข RFC |
| `Locator` | Single line of text | บท/หน้า ที่**มัก**อ้างถึง (ค่าตั้งต้น) |
| `URL` | Single line of text | **Text ธรรมดา ไม่ใช่ Hyperlink** — คอลัมน์ Hyperlink คืนค่าเป็น object |
| `Summary` | Multiple lines of text (plain) | **เนื้อหา/บันทึกความรู้** — แบ่งหัวข้อและแทรกลิงก์ได้ (ดูหัวข้อถัดไป) |
| `Topics` | Single line of text | หัวข้อ/แท็ก คั่นด้วย `,` เช่น `SRE, SLO, Monitoring` |
| `Media` | **Multiple lines of text (plain)** | คลิป/ลิงก์ **บรรทัดละ 1 ใส่ได้ไม่จำกัด** — ตั้งชื่อด้วย `ชื่อ \| ลิงก์` |

**List settings → Advanced settings → Attachments = Enabled**
(ไว้แนบสแกนหน้าหนังสือ หรือ PDF ของมาตรฐาน — เก็บที่คลังที่เดียว ทุกโครงการเปิดอ่านได้)

## ลิสต์ที่ 2 — `PM_ProjectReferences` (ลิสต์เชื่อม)

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | ชื่อแหล่งอ้างอิง ณ ตอนผูก (ไว้โชว์ถ้าคลังโหลดไม่ทัน) |
| `ProjectID` | **Number** | ต้องเป็น Number ไม่ใช่ Text |
| `ReferenceID` | **Number** | Id ของรายการใน `PM_References` |
| `Locator` | Single line of text | บท/หน้า ที่**โครงการนี้**อ้างถึง |
| `AppliedTo` | Single line of text | ใช้กับเรื่องอะไรในโครงการนี้ |

ไม่ต้องเปิด Attachments สำหรับลิสต์นี้

## ที่ได้จากการกรอกครบ

**บรรทัดอ้างอิงสำเร็จรูป** ประกอบให้อัตโนมัติ กดคัดลอกไปวางในรายงานได้เลย:

```
Beyer, B. (2016). Site Reliability Engineering (2nd ed.). O'Reilly Media. ISBN 978-1491929124. บทที่ 4 น.120-135. https://sre.google/books/
```

ช่องไหนไม่ได้กรอกก็หายไปทั้งช่อง ไม่ทิ้งจุดหรือวงเล็บเปล่าค้างไว้

ปุ่ม **คัดลอกบรรณานุกรม** มีทั้งสองที่ — ในคลังจะได้ตามรายการที่กรองอยู่
ในโครงการจะได้เฉพาะที่ผูกไว้ และใช้ `Locator` ของโครงการนั้นแทนค่าตั้งต้นจากคลัง

## คลิป YouTube — ใส่ได้ไม่จำกัด

ช่อง `Media` รับได้หลายบรรทัด บรรทัดละ 1 ลิงก์ ไม่จำกัดจำนวน:

```
https://youtu.be/xxxxxxxxxxx
ตอนที่ 2 — SLO | https://www.youtube.com/watch?v=yyyyyyyyyyy
คู่มือ vendor | https://vendor.example.com/guide.pdf
```

- **คลิป YouTube เล่นได้ในหน้าเลย** — แสดงเป็นรูปปกก่อน กดแล้วค่อยเล่น
  (ฝัง iframe ทุกอันตั้งแต่แรกจะทำให้หน้าหน่วง โดยเฉพาะรายการที่มีคลิปหลายสิบอัน)
- รองรับทุกรูปแบบลิงก์ที่ก็อปมาจริง: `youtu.be/`, `watch?v=`, `/shorts/`, `/live/` และ id เปล่า ๆ
- **ลิงก์ที่ไม่ใช่ YouTube** จะแสดงเป็นปุ่มเปิดแท็บใหม่ (เว็บส่วนใหญ่บล็อกการฝังอยู่แล้ว)
- ลิงก์ซ้ำและบรรทัดว่างถูกตัดทิ้งอัตโนมัติ

## เนื้อหาแสดงบนการ์ดเลย

เนื้อหาและคลิปแสดงบนการ์ดตั้งแต่แรก ไม่ต้องกดเปิด
หัวข้อแรกกางไว้ ที่เหลือพับ — กดที่ชื่อหัวข้อหรือสารบัญเพื่อกาง
ไฟล์แนบยังอยู่หลังปุ่ม 📎 เพราะไม่ได้ต้องดูทุกครั้ง

## สิทธิ์

| ทำอะไร | ใคร |
|---|---|
| ดูคลัง / คัดลอกอ้างอิง / ดาวน์โหลดไฟล์แนบ | ทุกคนที่เข้าหน้าแหล่งอ้างอิงได้ |
| เพิ่ม / แก้ไขรายการในคลัง / แนบไฟล์ | Agent ขึ้นไป |
| ลบออกจากคลัง | Boss / Admin เท่านั้น |
| ผูก / นำออก / แก้บริบทในโครงการ | Agent ขึ้นไป |

ตอนลบรายการที่ถูกใช้อยู่ ระบบจะเตือนว่าถูกอ้างอิงในกี่โครงการก่อน แล้วเก็บกวาดลิสต์เชื่อมให้

## ลบโครงการ

cascade delete ลบเฉพาะ **`PM_ProjectReferences`** ของโครงการนั้น
**คลัง `PM_References` ไม่ถูกแตะ** — ลบโครงการแล้วหนังสือต้องไม่หายไปจากองค์กร
