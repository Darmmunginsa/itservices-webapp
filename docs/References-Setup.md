# แหล่งอ้างอิงความรู้ในโครงการ (PM_References)

แท็บ **📚 อ้างอิง** ในหน้า Project detail — ใช้เก็บว่าโครงการนี้อ้างอิงความรู้จากที่ไหน
(หนังสือ, มาตรฐาน, RFC, เอกสารผู้ผลิต, คอร์ส ฯลฯ) พร้อมบอกได้ว่าอ้างถึง**หน้าไหน** และ
**เอาไปใช้กับเรื่องอะไร**

## ต้องสร้างลิสต์ก่อนใช้

SharePoint site เดียวกับ Helpdesk → **New → List** → ชื่อ **`PM_References`**

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | มีมาให้แล้ว — ใช้เป็น **ชื่อเรื่อง/ชื่อหนังสือ** |
| `ProjectID` | **Number** | ผูกกับโครงการ — ต้องเป็น Number ไม่ใช่ Text |
| `RefType` | Choice | `Book, Standard, RFC, Article, Vendor doc, Video, Course, Internal, Other` |
| `Authors` | Single line of text | ผู้แต่ง / องค์กรผู้ออกมาตรฐาน |
| `Year` | Single line of text | **เป็น Text ไม่ใช่ Number** — รองรับ "2016", "n.d.", "ค.ศ. 2019" |
| `Publisher` | Single line of text | สำนักพิมพ์ / ผู้เผยแพร่ |
| `Edition` | Single line of text | ครั้งที่พิมพ์ / เวอร์ชัน เช่น `2nd ed.`, `v3.1` |
| `Identifier` | Single line of text | ISBN / DOI / เลข RFC |
| `Locator` | Single line of text | ตำแหน่งที่อ้างถึงจริง เช่น `บทที่ 4 น.120-135` |
| `URL` | Single line of text | **Text ธรรมดา ไม่ใช่ Hyperlink** — คอลัมน์ Hyperlink คืนค่าเป็น object ทำให้อ่านยาก |
| `Summary` | Multiple lines of text (plain) | สรุปสาระ หรือข้อความที่ยกมา |
| `AppliedTo` | Single line of text | เอาไปใช้กับเรื่องอะไรในโครงการนี้ |

จากนั้น **List settings → Advanced settings → Attachments = Enabled**
(ไว้แนบสแกนหน้าหนังสือ หรือไฟล์ PDF ของมาตรฐาน)

> ถ้ายังไม่สร้างลิสต์ แท็บจะขึ้นข้อความบอกว่ายังไม่มีลิสต์ ไม่ทำให้หน้าโครงการพัง
> และคอลัมน์ที่ยังไม่ได้สร้างจะเว้นว่างไว้เฉย ๆ (หน้าเว็บดึงด้วย `select=*`)

## ที่ได้จากการกรอกครบ

**บรรทัดอ้างอิงสำเร็จรูป** ประกอบให้อัตโนมัติ กดปุ่มคัดลอกไปวางในรายงานได้เลย:

```
Beyer, B. (2016). Site Reliability Engineering (2nd ed.). O'Reilly Media. ISBN 978-1491929124. บทที่ 4 น.120-135. https://sre.google/books/
```

ช่องไหนไม่ได้กรอกก็หายไปทั้งช่อง ไม่ทิ้งจุดหรือวงเล็บเปล่าค้างไว้
และมีปุ่ม **คัดลอกบรรณานุกรม** ที่รวมทุกรายการในโครงการ เรียงตามตัวอักษรพร้อมเลขลำดับ

## สิทธิ์

| ทำอะไร | ใคร |
|---|---|
| ดู / คัดลอกอ้างอิง / ดาวน์โหลดไฟล์แนบ | ทุกคนที่เข้าหน้าโครงการนั้นได้ |
| เพิ่ม / แก้ไข / แนบไฟล์ | Agent ขึ้นไป |
| ลบ | Boss / Admin เท่านั้น |

ที่ลบได้เฉพาะ Boss/Admin เพราะแหล่งอ้างอิงที่ถูกลบไปแล้วตามกลับยาก — ต่างจาก Link ที่หาใหม่ได้

## ลบโครงการ

`PM_References` ถูกเพิ่มใน cascade delete แล้ว — ลบโครงการจะลบแหล่งอ้างอิงของโครงการนั้นตามไปด้วย
และนับรวมอยู่ในกล่องยืนยันก่อนลบ
