# ข้อความตอบกลับตอนปิดงาน + แนบลิงก์บทความความรู้

ตอนปิด **Ticket** (Resolved/Closed) หรือ **Incident** (Resolved) เลือกข้อความสำเร็จรูปได้
พร้อมแนบลิงก์บทความจากคลังความรู้ที่เผยแพร่ไว้แล้ว

```
ปิดงาน → เลือกข้อความตอบกลับ → แนบบทความ (ถ้ามี)
                    │
                    ▼
     ข้อความถูกเติมค่าให้อัตโนมัติ + มีลิงก์บทความ
                    │
                    ├─► บันทึกเป็น ResolutionNote
                    └─► (Ticket) ส่งถึงลูกค้าในเธรดเมลเดิม ถ้าติ๊กไว้
```

---

## ลิสต์ที่ต้องสร้าง — `HD_CloseTemplates`

| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `Title` | Single line of text | ชื่อข้อความ เช่น "ปิดงาน — แก้ไขเรียบร้อย" |
| `Body` | **Multiple lines of text (plain)** | เนื้อความ ใส่ตัวแปรได้ |
| `AppliesTo` | Choice | `Both`, `Ticket`, `Incident` (ว่าง = ทั้งคู่) |
| `Category` | Single line of text | ไม่ใส่ก็ได้ — ตรงกับหมวดงานไหนจะถูกเสนอขึ้นก่อน |
| `IsActive` | Yes/No | ปิดใช้โดยไม่ต้องลบ |

### ที่อยู่เว็บคลังความรู้

เก็บใน `HD_Options` แถวที่ `Category = KbBaseUrl` และ `Title = https://itservices.co.th/kb`

**ตั้งได้จากในหน้าจอ** — ปุ่ม **แนบบทความ** → ช่องบนสุด (ระบบสร้างแถวให้เอง)
เก็บใน SharePoint จึงใช้ร่วมกันทั้งทีม ไม่ต้องตั้งทีละเครื่อง

> ยังไม่สร้าง `HD_CloseTemplates` ก็ปิดงานได้ตามปกติ แค่ไม่มีข้อความสำเร็จรูปให้เลือก

## ตัวแปรในข้อความ

| ตัวแปร | ค่า |
|---|---|
| `{{ticket_number}}` | เลข Ticket (Incident ใช้ชื่อโครงการ) |
| `{{title}}` | ชื่อเรื่อง |
| `{{customer_name}}` | ชื่อผู้แจ้ง (Incident ใช้ชื่อบริษัทของโครงการ) |
| `{{agent_name}}` | ชื่อคนที่ปิดงาน |
| `{{resolution}}` | สรุปการแก้ไขที่พิมพ์ไว้ |
| `{{kb_links}}` | ลิงก์บทความที่แนบ |

**บรรทัดที่มีแต่ตัวแปรว่าง จะถูกตัดทิ้งทั้งบรรทัด** — ไม่ได้แนบบทความ ก็จะไม่เหลือ
"อ่านรายละเอียดเพิ่มเติมได้ที่:" ค้างอยู่โดยไม่มีอะไรตามมา ซึ่งดูเหมือนระบบพัง

## เริ่มใช้งาน

1. ปิดงานสักใบ → กด **จัดการข้อความ** (Supervisor ขึ้นไป)
2. กด **ใส่ตัวอย่างให้ 3 แบบ** — ได้ template พร้อมใช้ทันที แก้ต่อได้
3. ครั้งต่อไปเลือกจาก dropdown ได้เลย

## แนบบทความ

- เห็นเฉพาะบทความที่ **ตั้งเป็น "เผยแพร่" แล้ว** — ฉบับร่างส่งลิงก์ไปลูกค้าเปิดไม่ได้
- เลือกได้หลายบทความ · ค้นหาจากชื่อ/รหัส/ผลิตภัณฑ์/แท็ก
- **ลิงก์ตรงกับชื่อไฟล์ที่ปุ่ม "สร้างเว็บ" ปล่อยออกมา** (`its000123.html`)
- ถ้ายังไม่ได้ตั้งที่อยู่เว็บ จะขึ้นเตือนว่าลิงก์ที่ส่งไปจะกดไม่ได้

> ⚠️ บทความต้อง**ถูกอัปโหลดขึ้นเว็บแล้ว**ด้วย ไม่ใช่แค่ตั้งเป็นเผยแพร่ในระบบ —
> ระบบไม่มีทางรู้ว่าไฟล์ถูกอัปโหลดหรือยัง

## ส่งถึงลูกค้า (เฉพาะ Ticket)

ติ๊ก **"ส่งข้อความนี้ถึงลูกค้าด้วย"** ตอนปิดงาน → ระบบจะ:

1. บันทึกเป็นคอมเมนต์ **"ถึงลูกค้า"** ใน Ticket
2. ส่งอีเมล**ในเธรดเดิม** (หัวข้อเดียวกับที่ลูกค้าแจ้งมา) CC ทีมตามปกติ

ต้องเปิด template **"Comment Added"** ไว้ก่อน (ดู Ticket-Email-Thread.md)
ถ้ายังไม่เปิด งานจะถูกปิดตามปกติแต่เมลไม่ออก และระบบจะบอกเหตุผล

**Incident ไม่มีปุ่มส่งเมล** — Incident เป็นงานภายในโครงการ ไม่ได้ผูกกับอีเมลลูกค้าโดยตรง
ข้อความจะถูกบันทึกไว้ในช่อง Resolution เท่านั้น
