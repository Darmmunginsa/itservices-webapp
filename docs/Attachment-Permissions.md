# สิทธิ์แนบไฟล์ — ให้ทุกคนแนบได้ และบอกเหตุเมื่อแนบไม่ได้

## อาการที่พบ

"ผู้ใช้บางคนแนบไฟล์ที่ Task ไม่ได้" — มีสองสาเหตุที่ให้อาการเดียวกัน แต่แก้คนละที่:

| สาเหตุ | อยู่ที่ | ใครแก้ |
|---|---|---|
| **แอปซ่อนปุ่ม** ตาม role | โค้ด | ผม — แก้แล้ว |
| **SharePoint ปฏิเสธ** (ไม่มีสิทธิ์ Contribute / ลิสต์ปิด Attachments) | SharePoint | Admin — ตอนนี้แอปบอกแล้วว่าติดอันไหน |

## 1. แอปซ่อนปุ่ม (แก้แล้ว)

| ที่ | เดิม | ตอนนี้ |
|---|---|---|
| หน้าโครงการ → การ์ด **Task** | ปุ่มคลิปอยู่ใน `isAgent` — role EndUser **ไม่มีปุ่มเลย** ทั้งที่ Note ข้าง ๆ ให้แนบได้ | ทุกคนที่เห็นงานเห็นปุ่ม (แก้/ลบยังเป็นของ agent) |
| หน้า **Incident** → ไฟล์แนบ | `readOnly` เมื่อไม่ใช่ agent | แนบได้ทุกคน — ผู้แจ้งมักเป็นคนมีหลักฐาน (screenshot/log) |

หลัก: **สิทธิ์จริงคุมที่ SharePoint ไม่ใช่ที่การซ่อนปุ่ม** — ซ่อนปุ่มแล้วคนที่มีสิทธิ์จริงก็แนบไม่ได้ ส่วนคนที่ไม่มีสิทธิ์ก็ยังยิง API ได้อยู่ดี

ที่**ยังคง**จำกัดโดยตั้งใจ (เป็นทะเบียนของ Admin ไม่ใช่งาน): Assets · Portals · PhishReports · References/Tools ตามเจ้าของ

## 2. SharePoint ปฏิเสธ — ตอนนี้บอกเหตุจริง

เดิมทุกกรณีขึ้น **"อัปโหลดไม่สำเร็จ"** คำเดียว คนไม่มีสิทธิ์กับคนที่เจอลิสต์ปิดแนบไฟล์เห็นเหมือนกัน แล้วก็มาแจ้งว่า "ระบบพัง"

| HTTP | ข้อความตอนนี้ |
|---|---|
| 403 / 401 | ไม่มีสิทธิ์แนบไฟล์ในลิสต์ X — ต้องได้ **Contribute** ให้ Admin เพิ่มใน SharePoint |
| 400 (attachment) | ลิสต์ X **ปิดการแนบไฟล์** — List Settings → Advanced settings → Attachments |
| 413 | ไฟล์ใหญ่เกิน |
| 404 | ไม่พบรายการ/ลิสต์ |
| เครือข่าย | session หมดอายุ — รีเฟรช |

ใช้ทุกทางที่แนบไฟล์ (`spUploadAttachment` ตัวเดียว) — คอมเมนต์ Ticket/Incident/Project, ไฟล์แนบทุกลิสต์

## 3. หน้า Diagnostic ตรวจให้ล่วงหน้า

แต่ละลิสต์บอกแล้วว่า **คนที่ล็อกอินอยู่แนบไฟล์ได้ไหม**:

```
✔ PM_Tasks        เข้าถึงได้ · 📎 แนบไฟล์ได้
✔ PM_Incidents    เข้าถึงได้ · 📎 คุณไม่มีสิทธิ์แก้ไขลิสต์นี้ — แนบไฟล์ไม่ได้ (ต้อง Contribute)
✔ HD_Tickets      เข้าถึงได้ · 📎 ลิสต์ปิดการแนบไฟล์ (List Settings → Advanced → Attachments)
```

อ่านจาก `EffectiveBasePermissions` (สิทธิ์จริงของคนนั้นบนลิสต์นั้น) + `EnableAttachments`
**แนบไฟล์ต้องมี EditListItems** (แนบ = แก้ไขรายการ) ไม่ใช่แค่ AddListItems — คนที่ "สร้างได้แต่แนบไม่ได้" คือติดตรงนี้

> ให้คนที่แนบไม่ได้**เปิดหน้า Diagnostic ด้วยบัญชีของเขาเอง** — หน้านี้ตรวจสิทธิ์ของคนที่ล็อกอิน ไม่ใช่ของ Admin

## ที่ต้องทำใน SharePoint (ถ้า Diagnostic ฟ้อง)

- **ไม่มีสิทธิ์**: Site permissions → เพิ่มคน/กลุ่มเป็น **Contribute** (หรือ Edit) บนลิสต์นั้น — ถ้าลิสต์ break inheritance ต้องเพิ่มที่ลิสต์โดยตรง
- **ปิดแนบไฟล์**: List Settings → Advanced settings → Attachments → **Enabled**
