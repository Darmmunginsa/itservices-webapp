# บทบาทและความรับผิดชอบในโครงการ

ใช้ทีมที่ถูก **invite เข้าโครงการอยู่แล้ว** มากำหนดว่าใครทำหน้าที่อะไร
แล้วดูภาพรวมทุกคนทุกโครงการได้ที่หน้าผังองค์กร

เดิมรู้แค่ "อยู่ในทีม" ซึ่งตอบไม่ได้ว่า **ใครตัดสินใจ · ใครลงมือ · ใครแค่ดูอยู่**
พอโครงการเยอะขึ้น คำถาม "คนนี้รับผิดชอบอะไรอยู่บ้าง" ต้องไปถามกันเอง

---

## 1. ที่โครงการ → แท็บ 🎭 บทบาท

```
🎭 บทบาท (4)
⚠ โครงการนี้ยังไม่มีใครเป็น Manager — ยังไม่มีคนตัดสินใจแทนทีม

┌──────────────────────────┬──────────────────────────┐
│ อารีย์ รักงาน   [Manager]✎│ สมชาย ใจดี    [Support]✎ │
│ aree@its.co.th           │ somchai@its.co.th        │
│ อนุมัติการเปลี่ยนแปลง      │ ดูแล VDA รายวัน           │
├──────────────────────────┼──────────────────────────┤
│ กมล  [ยังไม่กำหนด]      ✎│ ...                      │
└──────────────────────────┴──────────────────────────┘
```

- เรียง **Manager → Assistant → Support → Publisher → Reviewer → Observer**
  แล้วคนที่ยังไม่กำหนดบทบาทอยู่ท้ายสุด (เพราะเป็นสิ่งที่ต้องไปตามให้ครบ)
- ช่อง **ความรับผิดชอบ** เป็นข้อความอิสระ เขียนอะไรก็ได้
- แก้ได้โดยคนที่จัดการทีมได้ (เจ้าของโครงการ · สมาชิกในทีม · Boss/Admin)

## 2. ที่ผังองค์กร → มุมมอง 🎭 บทบาทในโครงการ

```
[ สายบังคับบัญชา ] [ 🎭 บทบาทในโครงการ ]

ที่นั่งทั้งหมด: Manager·3  Support·5  Publisher·2  ยังไม่กำหนด·4
⚠ ยังไม่มี Manager อยู่ 2 โครงการ — #Backup, #Nextcloud

┌────────────────────────────┐
│ 🧑 สมชาย ใจดี    [Manager] │
│ กำลังถืออยู่ 2 โครงการ · จบแล้ว 1│
│ ┌ #Backup   [Manager]      │
│ ┌ #VDI      [Support]      │
│ │   ดูแล VDA รายวัน         │
│ └ #เก่า      [Publisher]    │
└────────────────────────────┘
```

- **เห็นทุกคน** ว่าอยู่โครงการอะไร ทำหน้าที่อะไร พร้อมข้อความความรับผิดชอบ
- **ช่องค้นหาเดียวกัน** ใช้ได้ทั้งสองมุมมอง — ค้นจากชื่อ / อีเมล / บทบาท /
  ชื่อโครงการ / ข้อความความรับผิดชอบ
- **รูปคนเดียวกับผังบังคับบัญชา** ไม่ต้องอัปโหลดใหม่
- กดชื่อโครงการเข้าโครงการนั้นได้ทันที
- โหลดข้อมูลทีมเฉพาะตอนเข้ามุมมองนี้ — คนที่มาดูผังปกติไม่ต้องรอ

---

## ⚠️ ต้องเพิ่ม 2 คอลัมน์ใน `PM_ProjectMembers`

| คอลัมน์ | ชนิด |
|---|---|
| `Role` | Single line of text |
| `Responsibility` | **Multiple lines of text (plain)** |

> ยังไม่เพิ่ม → **แท็บและมุมมองเปิดได้** แต่ทุกคนจะขึ้นว่า "ยังไม่กำหนด"
> และตอนกดบันทึกจะขึ้นข้อความบอกว่าคอลัมน์ยังไม่มี (ไม่ใช่ "เกิดข้อผิดพลาด" ลอย ๆ)

### เพิ่ม/แก้รายชื่อบทบาทเองได้

ตั้งต้นให้ 6 อย่าง: **Manager · Assistant · Support · Publisher · Reviewer · Observer**

เพิ่มของตัวเองได้ที่ `HD_Options` หมวด **`ProjectRole`** (ที่เดียวกับ option list อื่น)
บทบาทที่ตั้งเองจะเรียงอยู่กลาง ๆ — หลังชุดตั้งต้น แต่ยังมาก่อน "ยังไม่กำหนด"

## สิ่งที่ระบบเตือนให้เอง

| เตือน | ที่ไหน |
|---|---|
| โครงการนี้ยังไม่มี Manager | บนแท็บบทบาทของโครงการนั้น |
| ยังไม่มี Manager อยู่กี่โครงการ + ชื่อโครงการ | บนมุมมองบทบาท (กดเข้าได้เลย) |
| คนที่ยังไม่ได้กำหนดบทบาท | ป้ายสีส้ม |

**นับเป็น "ที่นั่ง" ไม่ใช่จำนวนคน** — คนเดียวเป็น Manager สองโครงการ นับสองที่นั่ง

**"กำลังถืออยู่ N โครงการ" ไม่รวมโครงการที่ Completed/Cancelled** เพราะงานที่จบแล้ว
ไม่ใช่ภาระที่ถืออยู่ (แต่ยังแสดงไว้แบบจาง ๆ เพื่อดูประวัติได้)

## ข้อจำกัด

- **คนที่ยังไม่ถูกเชิญเข้าโครงการไหนเลย จะไม่อยู่ในมุมมองบทบาท** — มุมมองนี้อ่านจาก
  ทีมโครงการ ไม่ใช่จากทะเบียนพนักงาน (จำนวนพนักงานทั้งหมดแสดงไว้ท้ายหน้าให้เทียบ)
- สมาชิกที่ผูกกับโครงการที่ถูกลบไปแล้ว **ไม่แสดง** ไม่ใช่ขึ้นเป็นบรรทัดที่กดไม่ได้
- คนหนึ่งมี **บทบาทเดียวต่อโครงการ** — ถ้าต้องมีหลายบทบาทในโครงการเดียว
  ให้เขียนรวมในช่องความรับผิดชอบ

## 27 ข้อทดสอบ

อยู่ใน `npm run check:report` — คุมการเรียงลำดับบทบาท การรวมรายคนข้ามโครงการ
การนับที่นั่ง การไม่นับโครงการที่จบแล้ว การค้นหาทุกช่อง และการหาโครงการที่ขาด Manager
