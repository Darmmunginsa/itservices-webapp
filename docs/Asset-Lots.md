# ตะกร้า (Lot) ของ IT Asset

## ปัญหา

ซื้อโน้ตบุ๊ก 10 เครื่องใบส่งของใบเดียว แต่ Asset เป็น 10 แถว — **ใบรับสินค้า / ใบกำกับภาษี / PO จะไปแนบที่เครื่องไหน?**
แนบทั้ง 10 ก็ซ้ำ แนบเครื่องเดียวก็หาไม่เจอ และไม่มีที่ไหนบอกว่า 10 เครื่องนี้มาด้วยกัน

## ตอนนี้

```
🧺 ตะกร้า LOT-2026-003 · โน้ตบุ๊กทีมขาย ก.ย. 69     ซื้อ 15 ก.ย. 69 · Dell · PO-1234
   📄 เอกสาร: ใบส่งของ.pdf · ใบกำกับ.pdf · ใบรับประกัน.pdf        ← แนบที่ตะกร้าแถวเดียว
   ของในตะกร้า 10 ชิ้น · ราคารวม 300,000 (ยอดใบส่งของ 300,000)
     IT-2026-041  Dell Latitude 5540 #01   Active   30,000
     IT-2026-042  Dell Latitude 5540 #02   Active   30,000
     …
   [ย้ายของเข้า]  [สร้างหลายชิ้น]
```

| ที่ | ทำอะไรได้ |
|---|---|
| **แถบตะกร้า** บนหน้า Assets | เห็นทุกตะกร้า: เลข · ชื่อ · วันซื้อ · จำนวนชิ้น · ยอด · 📎 จำนวนเอกสาร — ปุ่ม "ตะกร้า (N)" พับ/กางได้ |
| **ตะกร้าใหม่** | ชื่อ · เลขตะกร้า (auto `LOT-ปี-ลำดับ`) · วันซื้อ · Vendor · PO · ใบกำกับ · ยอด · ใบเสนอราคา · หมายเหตุ — **แนบใบส่งของได้ตั้งแต่ตอนสร้าง** แล้วเปิดตะกร้าให้ต่อเลย |
| **ย้ายของเข้า** | ติ๊กเลือกจาก Asset ที่ยังไม่อยู่ในตะกร้าไหน (ค้นชื่อ/รหัส/serial) |
| **สร้างหลายชิ้น** | ชื่อรุ่น × จำนวน → `Dell 5540 #01…#10` รหัส Asset รันต่อ · วันซื้อ/ผู้ขาย/ใบเสนอราคา ดึงจากตะกร้า · ราคาต่อชิ้น + หมดประกัน ใส่ครั้งเดียว |
| **เอาออก** | ล้าง LotID ที่ Asset — ตัว Asset ยังอยู่ (ตะกร้าแค่จัดกลุ่ม ไม่ได้เป็นเจ้าของ) |
| **ลบตะกร้า** | Asset ข้างในยังอยู่ แค่ไม่มีตะกร้า · เอกสารของตะกร้าหายไป (ถามก่อน) |
| **หน้า Asset** | ช่อง "🧺 ตะกร้า" ในฟอร์ม · รายละเอียดโชว์ตะกร้า + "📎 เอกสาร N ไฟล์ที่ตะกร้า" กดไปดูได้ · Excel มีคอลัมน์ตะกร้า |

**เตือนยอดไม่ตรง** — ถ้ายอดใบส่งของกับราคารวม Asset ต่างกัน จะบอกส่วนต่าง: บวก = มี Asset ที่ยังไม่ได้ใส่ราคา/ยังไม่ได้สร้าง, ลบ = ราคาเกิน

## ต้องสร้างใน SharePoint

**1. ลิสต์ `IT_AssetLots`** (Custom list) — **เปิด Attachments** (List settings → Advanced → Attachments: Enabled)

| คอลัมน์ | ชนิด |
|---|---|
| Title | (มีอยู่แล้ว) ชื่อตะกร้า |
| LotNo | Single line |
| PurchaseDate | Date |
| Vendor | Single line |
| VendorID | Number |
| PONumber | Single line |
| InvoiceNo | Single line |
| TotalCost | Number |
| QuotationRef | Single line |
| Note | Multiple lines (plain) |

**2. `IT_Assets` เพิ่มคอลัมน์ `LotID`** — Number

> ยังไม่สร้างลิสต์ = หน้า Assets **ซ่อนทุกอย่างเกี่ยวกับตะกร้า** ใช้งานได้ตามปกติ และฟอร์ม Asset จะไม่ส่งคอลัมน์ LotID เลย (กันบันทึกพังเมื่อคอลัมน์ยังไม่มี)
