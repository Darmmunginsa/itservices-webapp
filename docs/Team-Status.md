# สถานะทีม (Team Status)

หน้า "ใครว่าง ใครไม่ว่าง ตอนนี้" ของทีม — ตั้งสถานะตัวเองได้ในคลิกเดียว ทีมเห็นทันที (รีเฟรชทุก 30 วิ)
พร้อมไทม์ไลน์รายวัน และซ้อนประชุมจากปฏิทิน Outlook ให้โดยไม่ต้องกรอกซ้ำ

```
สถานะของฉัน   🟢 ว่าง — ทีมติดต่อได้                      [แจ้งว่าไม่ว่าง]
วันนี้  ◀ ▶                                   ว่าง 4/7 คน
 ● สมชาย (ฉัน)   ว่าง
 ● อารีย์         ประชุม · ประชุมลูกค้า · เหลืออีก 40 นาที
 ● บอส           📅 Weekly sync · ถึง 11:00        ← จาก Outlook
ไทม์ไลน์  08:00 ──── 12:00 ──── 20:00   | เส้นแดง = ตอนนี้
```

| สถานะ | ว่างไหม |
|---|---|
| ว่าง · พัก | ว่าง |
| ไม่ว่าง · ประชุม · ออกไซต์ · เลิกงาน/ลา | ไม่ว่าง |

ตั้งสถานะ = เลือกชนิด + เหตุผล (มีตัวเลือกบ่อย ๆ) + นาน 15 นาที…ถึงสิ้นวัน (20:00) · กด **เสร็จแล้ว / ว่าง** จบก่อนกำหนดได้
ไม่มี slot ครอบเวลาตอนนี้ = ว่างโดยปริยาย · ใช้ชุดเดียวกับแอปมือถือ (`itservices-helpdesk-phone`)

## ต้องสร้างใน SharePoint

**1. ลิสต์ `HD_TeamStatus`**

| คอลัมน์ | ชนิด |
|---|---|
| Title | เหตุผลสั้น ๆ (มีอยู่แล้ว) |
| UserEmail · UserName | Single line |
| StatusType | Choice: `Available` `Busy` `Meeting` `OnSite` `Break` `Off` |
| StartTime · EndTime | Date and Time (รวมเวลา) — **index EndTime** ถ้าแถวจะเกิน 5,000 |
| Note | Multiple lines (plain) |

**2. `HD_AgentProfiles` เพิ่ม `ShowInTeamStatus`** (Yes/No, default Yes) — Admin › แท็บ "สถานะทีม" ปิดสวิตช์เพื่อซ่อนคน (เช่น ผู้บริหาร)
ยังไม่สร้างคอลัมน์ = แสดงทุกคน (โค้ด fallback ให้)

**3. สิทธิ์หน้า** — หน้าใหม่ `team-status` (กลุ่มหน้าหลัก) · คนที่มีแถวสิทธิ์อยู่แล้ว**ยังไม่เห็น** จนกว่า Admin จะติ๊กให้ที่ "สิทธิ์การเข้าถึงหน้า"

## ซ้อนประชุมจาก Outlook — ต้องตั้งใน Azure AD

ใช้ Graph `getSchedule` ด้วย scope **`Calendars.Read.Shared`** (ขอ token แยกใบ แบบ silent เท่านั้น)
→ App registration › API permissions › เพิ่ม delegated `Calendars.Read.Shared` › **Grant admin consent**

ยังไม่ consent = หน้าใช้ได้ปกติ แค่ไม่มีแถบ Outlook (ไม่ขึ้น error) · เห็นหัวข้อประชุมเฉพาะปฏิทินที่เรามีสิทธิ์ดูรายละเอียด ที่เหลือขึ้น "ประชุม (Outlook)"

## ออฟฟิศเสมือน (แบบ "มอง")

มุมมองเริ่มต้นของวันนี้ — แผนผัง 6 ห้อง อวาตาร์ (รูปจากผังองค์กร) **ย้ายห้องเองตามสถานะ** กดคนแล้วทักได้ทันที

```
🪑 โต๊ะทำงาน 3     🎧 ห้องโฟกัส 1     🗣️ ห้องประชุม 2
  (ฉัน) อารีย์ บี       สมชาย            บอส  นัท
🚗 ไซต์ลูกค้า 1     ☕ มุมพัก 0         🌙 ไม่อยู่ 1
  ก้อง                — ว่าง —           แพร

[รูป] สมชาย · ไม่ว่าง · แก้ปัญหาด่วน · เหลืออีก 40 นาที   [แชท Teams] [โทร] [เมล]
```

| สถานะ | ห้อง |
|---|---|
| ไม่ได้ตั้ง / ว่าง | โต๊ะทำงาน — ถ้ามีนัดใน Outlook ครอบเวลานี้ → ห้องประชุม |
| ไม่ว่าง | ห้องโฟกัส |
| ประชุม | ห้องประชุม |
| ออกไซต์ | ไซต์ลูกค้า |
| พัก | มุมพัก |
| เลิกงาน/ลา | ไม่อยู่ |

สถานะที่ตั้งเอง**มาก่อน**ปฏิทิน — กด "ออกไซต์" ทั้งที่มีนัด Outlook ค้าง ก็อยู่ไซต์

**ทัก = Microsoft Teams** ที่ทุกคนมีอยู่แล้ว (deep link เปิดแชท / โทร) — ไม่ได้ทำแชทในแอป เพราะจะเป็น "อีกที่ที่ต้องเปิด" และเว็บ static ไม่มี realtime/เสียงตามระยะแบบ Gather · ปุ่มโทรจางลงเมื่อคนนั้นไม่ว่าง
กดตัวเองได้ "เสร็จแล้ว / ว่าง" และ "ตั้งใหม่" จากการ์ดเลย · สลับเป็นแบบรายการได้ที่ปุ่มมุมขวา (จำค่าไว้)

## ออฟฟิศ 2D เดินได้ (เฟส A — แบบ Gather โดยไม่มี server)

มุมมองเริ่มต้นของหน้าสถานะทีม (ปุ่ม "🏢 ออฟฟิศ" / "📋 สถานะ & ไทม์ไลน์" จำค่าไว้)

```
┌ โต๊ะทำงาน ─────────┬ ห้องประชุม ────────┐   ┌ แชท ─────────────┐
│ 🖥️🖥️  🖥️🖥️  🖥️🖥️   │  ▓▓▓▓ (โต๊ะประชุม) │   │ ทั้งออฟฟิศ | ห้องนี้ │
│   (ฉัน)   ก้อง →     │   อารีย์           │   │ ก้อง: สวัสดี…     │
├ ห้องโฟกัส ┬ มุมกาแฟ ☕ ┬ ออกไซต์ 🚪 ┤   │ [พิมพ์…]      ▶  │
```

| ทำอะไร | ยังไง |
|---|---|
| **เดิน** | คลิกแผนที่ให้โฟกัส แล้วลูกศร / WASD (กดค้างเดินต่อเนื่อง) · หรือ**คลิกช่องว่าง**แล้วเดินไปเอง (BFS อ้อมกำแพง/โต๊ะ ทีละก้าว) |
| **เข้าโซน = สถานะเปลี่ยนเอง** | ห้องประชุม→ประชุม · ห้องโฟกัส→ไม่ว่าง · มุมกาแฟ→พัก · ประตู/โซนไซต์→ออกไซต์ · กลับโต๊ะ→ว่าง (จบ slot ที่เกิดจากการเดินเท่านั้น — สถานะที่ตั้งมือจากปุ่มไม่โดนแตะ) |
| **คนอื่น** | เห็นเฉพาะคนออนไลน์ (heartbeat ≤ 90 วิ) · ตำแหน่งอัปเดตทุก 3 วิ แล้ว**เลื่อนไปช้า ๆ 2.4 วิ** ให้ดูเหมือนเดิน ไม่วาร์ป · วงแหวนสี = สถานะ · คลิกอวาตาร์ = เปิดแชท Teams |
| **แชท** | แท็บ "ทั้งออฟฟิศ" / "ห้องที่ยืนอยู่ (N)" — ข้อความห้องเห็นเฉพาะคนในโซนนั้น · Enter ส่ง · อัปเดตทุก 3 วิ |

ทำไม 3 วิ: SharePoint รับ 20 คน × poll ทุก 3 วิ ≈ 7 req/วิ ได้สบาย · ตำแหน่งเขียนรวมหลายก้าวเป็นครั้งเดียวทุก 1.5 วิ ไม่ยิงทุกก้าว

### แก้ผังออฟฟิศเองใน Admin (แท็บ "🗺️ ผังออฟฟิศ")

ไม่ต้องพิมพ์ตัวอักษร — **เลือกชนิดช่องแล้วคลิก/ลากระบาย** บนผัง

- จานสี 12 ชนิด: พื้น · กำแพง · ห้องประชุม · โฟกัส · มุมกาแฟ · โซนไซต์ · ประตู · โต๊ะ+คอม · โต๊ะประชุม · ต้นไม้ · เครื่องกาแฟ · ไวท์บอร์ด
- ย่อ/ขยาย 8–60 ช่อง (ขอบนอกเป็นกำแพงเสมอ) · ย้อนกลับทีละการลาก · ล้างผัง · กลับผังมาตรฐาน
- **ตรวจก่อนบันทึก** — บันทึกไม่ได้ถ้า: ขอบมีรู · ไม่มีพื้นโต๊ะทำงาน (จุดเกิด) · ตัวอักษรแปลก · เตือนถ้า: มีห้องที่เดินไปไม่ถึง (ถูกกำแพงล้อม) · ไม่มีห้องประชุม/โฟกัส/กาแฟ/ไซต์ (สถานะนั้นตั้งด้วยการเดินไม่ได้)
  — ตัวตรวจนี้จับได้ทันทีว่าผังมาตรฐานรุ่นแรกมีโซนไซต์ที่เข้าไม่ถึง
- จุดสีน้ำเงิน = จุดเกิดของคนที่เข้าออฟฟิศครั้งแรก

เก็บใน `HD_Options` Category=`OfficeMap` **1 แถวต่อ 1 บรรทัดของผัง** (Title, SortOrder) — ใช้คอลัมน์ที่มีอยู่แล้ว ไม่ต้องสร้างอะไรเพิ่ม · บันทึกเขียนชุดใหม่ก่อนค่อยลบชุดเก่า ล้มกลางทางยังมีผังใช้ · คนที่ยืนอยู่บนช่องที่กลายเป็นกำแพงถูกย้ายไปจุดเกิดเอง

โค้ด: `setTile` `resizeMap` `blankMap` `validateMap` ใน `utils/officeMap.ts` (17 เทสต์) · [`src/components/admin/OfficeMapEditor.tsx`](../src/components/admin/OfficeMapEditor.tsx)

### ดึงออกไปอีกจอ

ปุ่ม **⧉ เปิดอีกหน้าต่าง** (ข้างปุ่มสลับออฟฟิศ/สถานะ) เปิด `#/team-status?popout=1` ในหน้าต่างใหม่ขนาด ~60% ของจอ (720–1180 px) ชิดขวา
— หน้าต่างนั้น**ไม่มีเมนูข้าง / ticker / ปุ่มลอย** เหลือแต่ออฟฟิศ + แชท ไว้วางอีกจอคู่กับงานอื่น · กดซ้ำ = โฟกัสหน้าต่างเดิม (ชื่อหน้าต่างเดียวกัน)

- ล็อกอินให้เอง — MSAL เก็บ token ใน localStorage ซึ่งหน้าต่างใหม่เห็นด้วย
- `?popout=1` อยู่หลัง `#` จึงไม่รบกวน redirect ของ MSAL
- **มีแชทใหม่ตอนไม่ได้มองหน้าต่าง** → ชื่อแท็บขึ้น `(3) สถานะทีม` และเด้ง **Notification** ของเบราว์เซอร์ถ้าอนุญาต (กระดิ่งที่หัวแชท) · กลับมามอง = เคลียร์
- ข้อความของตัวเองไม่นับ · รอบโหลดแรกไม่นับของเก่าเป็นใหม่
- หน้าต่างหลักกับหน้าต่างแยกเปิดพร้อมกันได้ (เขียนตำแหน่งแถวเดียวกัน) — แต่ควรเดินจากหน้าต่างเดียว

| โต๊ะประชุม | ต่อกันเป็นผืนเดียว (โค้งเฉพาะมุมนอก) ลายไม้ **เก้าอี้รอบโต๊ะ** ของบนโต๊ะสุ่มคงที่ตามตำแหน่ง (เอกสาร / โน้ตบุ๊ก / แก้วกาแฟ / ปากกา+โพสต์อิท) |
| ต้นไม้ / เครื่องกาแฟ / ไวท์บอร์ด | พุ่มหลายเฉด กระถางดินเผา · เครื่องชงมีไฟสถานะ **ไอร้อนลอยจากแก้ว** · กระดานมีลายมือ 3 สี ขาตั้ง ที่วางปากกา |

มิติ: เฟอร์นิเจอร์มี**เงาเบลอตกบนพื้น** (แสงจากซ้ายบน) และอยู่ชั้นสูงกว่าพื้นจึงล้นขอบได้ · เฟอร์นิเจอร์วางบน**พื้นของโซนรอบตัว** (โต๊ะในห้องประชุมอยู่บนพรม) · ทั้งห้องมีแสงอุ่นจากมุมซ้ายบนและขอบมืดเล็กน้อย · อวาตาร์มีเงาวงรีใต้เท้าและ**เด้งตัวทุกก้าว** (ปิดเองถ้าเครื่องตั้งลดการเคลื่อนไหว) · ป้ายโซนเป็นแผ่นป้ายติดผนัง · โหมดมืดหรี่ภาพลงให้กลืนกับธีม

ช่องใช้ `memo` และรับ `rows` (อ้างอิงคงที่) — ตอนเดินหรือ poll ทุก 3 วิ ช่องแผนที่ไม่วาดใหม่ วาดเฉพาะอวาตาร์

## คุยกันได้จริง — เสียงตามระยะ (ไม่มีค่าใช้จ่าย)

กด **🎧 เข้าร่วมเสียง** ที่หัวแผนที่ → ได้ยินคนที่**เปิดไมค์**และอยู่ใกล้ แบบ Gather

| อยู่ที่ไหน | ได้ยินใคร |
|---|---|
| ห้องประชุม / โฟกัส / มุมกาแฟ / ไซต์ | **ทุกคนในห้องเดียวกัน เต็มเสียง** · คนนอกห้องไม่ได้ยินเลย (แม้ยืนหน้าประตู) |
| โถงโต๊ะทำงาน | คนในรัศมี 3 ช่อง — ติดกัน 100% · 2 ช่อง 60% · 3 ช่อง 30% · ไกลกว่านั้นวางสายเอง |

- ปุ่ม **ไมค์เปิด / ปิดไมค์อยู่** (ปิดแล้วยังได้ยินคนอื่น) · **วางสาย** = ออกจากเสียง คืนไมค์
- อวาตาร์คนเปิดไมค์มีป้าย 🎙 · **กำลังพูด = วงแหวนเขียวกระเพื่อม** (ของเราเองด้วย ให้รู้ว่าไมค์ติด)
- แถบใต้หัวแผนที่บอกว่ากำลังคุยกับใคร ความดังเท่าไร หรือ "กำลังต่อ…"
- สายพร้อมกันได้สูงสุด 6 คน (ใกล้สุดก่อน) · ออกจากหน้า = วางทุกสาย
- ตัดเสียงก้อง/เสียงรบกวน/ปรับระดับอัตโนมัติ (ของเบราว์เซอร์)

### ทำงานยังไง

**WebRTC เครื่องต่อเครื่อง** — เสียงวิ่งตรงระหว่างเครื่อง ไม่ผ่าน server ใด ๆ (realtime จริง)
SharePoint ใช้แค่ "แนะนำตัว" ตอนเริ่มต่อสาย: ฝั่งอีเมลน้อยกว่าส่ง offer 1 ข้อความ อีกฝั่งตอบ answer 1 ข้อความ แล้วลบทิ้งทันที
→ ต่อสายใช้ ~2–4 วิ (รอบ poll 1.5 วิ) หลังจากนั้นเสียงไม่หน่วง · สถานะไมค์ฝากไปกับตำแหน่ง (ช่อง Room = `desk:mic`) ไม่ต้องเพิ่มคอลัมน์

**ทดสอบแล้วบนเบราว์เซอร์จริง** (`dev-preview/voice.html`): 2 คนยืนติดกัน ส่งเสียงสังเคราะห์ 440/660 Hz → ข้อความแนะนำตัว 2 ข้อความ → ทั้งคู่ `connected` และแต่ละฝั่งตรวจเจอเสียงของอีกฝั่ง

### ข้อจำกัดที่ต้องรู้

- **ไม่มี TURN server** (ตัวกลางส่งต่อเสียงเมื่อต่อตรงไม่ได้ — ตัวนี้แหละที่ต้องจ่ายเงิน) → **ในออฟฟิศเดียวกัน/วงแลนเดียวกันต่อได้แน่** · คนทำงานจากบ้านผ่านเน็ตบางเครือข่าย (NAT เข้มงวด, VPN บางตัว) อาจต่อไม่ติด — ระบบรอ 20 วิแล้วบอกให้ใช้ Teams แทน และพักคนนั้น 30 วิ
- ใช้ **STUN สาธารณะของ Google** (`stun.l.google.com`) เพื่อหาเส้นทางต่อตรง — Google เห็นแค่ IP ของเครื่อง **ไม่เห็นเสียง** · ถ้าไม่ต้องการ ลบออกได้ที่ `ICE_SERVERS` ใน `useOfficeVoice.ts` (จะเหลือใช้ได้เฉพาะวงแลนเดียวกัน)
- ต้องเปิดผ่าน **https** (เว็บจริงเป็นอยู่แล้ว) และอนุญาตไมโครโฟน
- เมื่อได้งบ Azure: เพิ่ม TURN (Azure Communication Services) ใน `ICE_SERVERS` + เปลี่ยน signaling เป็น Web PubSub → ต่อติดทุกเครือข่ายและต่อสาย <1 วิ โดยหน้าจอไม่ต้องแก้

## แชทส่วนตัว + ทักขอคุยเสียง

แท็บ **ส่วนตัว** ในช่องแชท (มีตัวเลขแดงเมื่อมีข้อความใหม่) · **กดที่ตัวคนบนแผนที่ = เปิดแชทส่วนตัวกับคนนั้น** (Teams ยังอยู่ที่ไอคอน ↗ ในหัวห้องแชท)

- รายชื่อ: คนที่เคยคุย (ใหม่สุดก่อน มีข้อความล่าสุด + จำนวนที่ยังไม่อ่าน) ตามด้วยคนที่ออนไลน์อยู่ · ค้นหาได้
- ยังไม่อ่าน = จำในเครื่อง · เปิดห้อง = อ่านแล้ว · ข้อความใหม่ตอนไม่ได้มอง → ชื่อแท็บ `(N)` + Notification

### ขอคุยเสียง — ถามก่อน ไม่โทรเข้าไปเลย

```
คุณ:  [📞 ขอคุยเสียง]
เขา:  ┌ 📞 สมชาย ถามว่า สะดวกคุยด้วยเสียงไหม?   [สะดวก] [ตอบในแชท] ┐   ← เด้งเหนือแผนที่ + ในห้องแชท
      └ ยังไม่สะดวก ▾  ติดประชุมอยู่ ขอ 10 นาที · ขอพิมพ์คุยแทนนะ · อีกสักครู่โทรกลับ
รับ → 🔒 กำลังคุยส่วนตัวกับ … — คนรอบตัวไม่ได้ยิน            [วางสาย]
```

- **สายส่วนตัว**: ต่อกันสองคน**ไม่สนระยะ** (คนละห้องก็ได้) · ระหว่างนั้น**ไม่รับสายจากคนรอบตัว** (ปฏิเสธทันที ไม่ปล่อยให้ได้ยินแม้ไม่กี่วินาที)
- รับแล้วไมค์ยังปิด → เปิดให้เอง · วางสาย → ไมค์ที่เปิดเพราะสายนี้ปิดคืน
- คำขอค้างได้ 2 นาที (เกินแล้วหายเอง ไม่ให้กดรับของเก่า) · "ไม่สะดวก" โชว์สั้น ๆ แล้วขอใหม่ได้ · รับสายใหม่ขณะคุยอยู่ = วางสายเก่าก่อน
- ทั้งสองฝั่งคำนวณสถานะจาก**แถวชุดเดียวกัน** (ขอ / รับ / ไม่สะดวก / วางสาย) จึงตรงกันเองโดยไม่ต้องส่งอะไรเพิ่ม

**ทดสอบแล้วบนเบราว์เซอร์**: กดที่ตัวคน → เปิดห้องแชท · อีกฝั่งขอ → แบนเนอร์ + การ์ดขึ้น, ชื่อแท็บ `(1)` · กดรับ → แบนเนอร์สายส่วนตัว, ไมค์เปิดเอง, 🔒 บนตัวคนนั้น · วางสาย → ไมค์ปิดคืน, บรรทัด "📴 คุณวางสาย"

### ⚠ เรื่องความเป็นส่วนตัว

แอปดึงเฉพาะข้อความที่เราเป็นผู้ส่งหรือผู้รับ (กรองที่ server) — **แต่สิทธิ์ใน SharePoint เป็นระดับลิสต์**: คนที่มีสิทธิ์อ่านลิสต์ `HD_OfficeDM` เปิดดูผ่าน SharePoint ตรง ๆ ได้ทุกแถว
→ ใช้สำหรับเรื่องงานทั่วไป · **เรื่องลับ/ส่วนตัวจริง ใช้ Teams** · ไม่ลง Activity Log
(ทำให้ลับจริงต้องตั้งสิทธิ์รายแถวผ่าน Power Automate ตอนสร้างแถว — ทำเพิ่มได้ถ้าต้องการ)

## แชร์หน้าจอ

เข้าร่วมเสียงแล้ว กด **🖥️ แชร์จอ** → เลือกจอ/หน้าต่าง/แท็บ → **คนที่กำลังคุยด้วยเห็นทันที**
(ห้องเดียวกันที่เปิดไมค์ หรือสายส่วนตัวจากแชท) · คนที่เดินเข้ามาทีหลังระหว่างแชร์ก็เห็นเอง · เดินออกห่าง = หลุดทั้งเสียงและภาพ

| ฝั่ง | เห็นอะไร |
|---|---|
| คนดู | เวทีเหนือแผนที่ แสดงจอที่แชร์ · หลายคนแชร์พร้อมกัน = ปุ่มชื่อมุมซ้ายบนเลือกดูทีละคน · ปุ่ม ⛶ เต็มจอ · ป้าย 🖥️ ที่ชื่อคนกำลังแชร์ |
| คนแชร์ | ภาพตัวอย่างขอบแดง "● กำลังแชร์" มุมขวาล่าง + บอกว่าแชร์ให้ใครอยู่ (ยังไม่มีใคร = บอกให้เดินไปหาคนดู) · **หยุดแชร์** ที่ปุ่มในแอป หรือแถบ "หยุดแชร์" ของเบราว์เซอร์ก็ได้ |

ทำงานบนสายเสียงเดิม (ตกลงเงื่อนไขใหม่ 1 รอบ: reoffer/reanswer) — **เสียงไม่หลุดตอนเริ่ม/หยุดแชร์** · ภาพตั้งให้ตัวหนังสือคม (`contentHint: detail`) 15 fps จำกัด 1.5 Mbps ต่อคนดู
ไม่มีค่าใช้จ่าย ข้อจำกัดเครือข่ายเหมือนเสียง (ในออฟฟิศเดียวกันได้แน่ ข้ามเน็ตบางแบบต้องมี TURN) · มือถือส่วนใหญ่แชร์ไม่ได้ (ปุ่มไม่โชว์) แต่ดูได้

**ทดสอบแล้วบนเบราว์เซอร์จริง** (`dev-preview/voice.html`): A แชร์ "จอ" สังเคราะห์ → B ได้ภาพวิ่ง 640×360 ภายในไม่กี่วินาที, เสียงยัง connected · A หยุดแชร์ → ภาพที่ B หาย เสียงยังอยู่

ไม่ต้องสร้างอะไรเพิ่มใน SharePoint (ใช้ `HD_OfficeSignal` เดิม)

## ปิดไมค์ / กดค้างเพื่อพูด — สำหรับห้องคนเยอะ

| ทำอะไร | วิธี |
|---|---|
| ปิด/เปิดไมค์ | ปุ่มที่หัวแผนที่ หรือกด **M** · ปิดแล้วยังได้ยินคนอื่นตามปกติ |
| พูดชั่วคราวตอนปิดไมค์ | **กดค้าง Space** — ปล่อยแล้วกลับเงียบ (push-to-talk) · สลับหน้าต่างกลางทาง = ตัดเสียงให้เอง |
| เข้าห้องคนเยอะ | เข้าร่วมเสียงตอนที่มีคนได้ยินเรา 2 คนขึ้นไป → **เริ่มแบบปิดไมค์** พร้อมบอกวิธีพูด |
| รู้ว่าใครปิดไมค์ | ป้าย 🔇 สีแดงบนตัวคนนั้น (ของเราเองด้วย) · 🔇 ที่ชื่อในแถบคนที่คุยด้วย |

- ปุ่มเขียนเป็น**สิ่งที่จะเกิดเมื่อกด** ("ปิดไมค์" / "เปิดไมค์") — เดิมเป็นป้ายสถานะ "ไมค์เปิด" ดูไม่ออกว่ากดได้ คนเลยหาปุ่มปิดไมค์ไม่เจอ · ปิดอยู่ = ปุ่มแดง + บรรทัดเตือนใต้หัวแผนที่
- คีย์ลัดไม่ทำงานตอนพิมพ์ในช่องข้อความ (พิมพ์คำที่มี m / เว้นวรรค ไม่ไปสลับไมค์)
- สถานะปิดไมค์ส่งไปกับตำแหน่ง (ช่อง Room = `meeting:muted`) — ไม่ต้องเพิ่มคอลัมน์

**ทดสอบแล้วบนเบราว์เซอร์จริง** (2 คนต่อสายกัน วัดว่าอีกฝั่ง "ได้ยิน" ไหม): ต่อสาย = ได้ยิน · ปิดไมค์ = ไม่ได้ยิน · กดค้างพูด = ได้ยิน · ปล่อย = ไม่ได้ยิน และยังปิดไมค์อยู่ · เปิดไมค์ = ได้ยิน
และบนหน้าออฟฟิศ: M สลับ, Space ค้าง = "กำลังพูด…", พิมพ์ M ในช่องแชทไม่สลับไมค์

### โหมดโรงหนัง — จอที่แชร์เป็นพื้นที่หลัก

มีคนแชร์ → **จอที่แชร์ขยายเต็มพื้นที่หลักแทนแผนที่เอง** (สูงเกือบเต็มหน้าต่าง) แชทยังอยู่ด้านขวา — แบบเดียวกับ Teams/Gather

| ปุ่มบนจอ | ทำอะไร |
|---|---|
| 🗺️ แผนที่ | ย่อจอลง กลับไปเห็นแผนที่ (เดินต่อได้) |
| ⤢ ขยาย | กลับเป็นโหมดโรงหนัง |
| ⛶ / ดับเบิลคลิกที่ภาพ | เต็มจอทั้งจอ (Esc ออก) |

## ตกแต่งโต๊ะของตัวเอง

ปุ่ม **🎨 จองโต๊ะ / ตกแต่งโต๊ะ** ที่หัวแผนที่ → ช่องแชทกลายเป็นแผงตกแต่งชั่วคราว

1. **วางโต๊ะของฉันตรงไหนก็ได้** — เลือกแบบโต๊ะ แล้วคลิกช่องเขียวบนพื้น**โซนโต๊ะทำงาน หรือห้องโฟกัส** · ป้ายชื่อเหนือโต๊ะ ("โต๊ะฉัน" / ชื่อเจ้าของ)
   - **แบบโต๊ะ 9 แบบ**: ไม้คลาสสิก · มินิมอลขาว · โต๊ะยืน · เกมมิ่ง RGB (ไฟวิ่ง) · ผู้บริหาร · ตัว L (จอคู่) · กระจก · โต๊ะเขียนแบบ · โต๊ะกลมคาเฟ่ — แต่ละแบบมีเก้าอี้ของตัวเอง
   - **เปลี่ยนแบบได้ตลอด** (ของบนโต๊ะไม่หาย) · **หมุนโต๊ะ** 90° ให้เก้าอี้หันทิศที่ชอบ
   - โต๊ะที่อยู่ในผังเดิม = **โต๊ะส่วนกลาง (hot desk)** ใช้ร่วมกัน ไม่มีใครเป็นเจ้าของ
   - ห้ามวางชิดโต๊ะคนอื่น (เว้นอย่างน้อย 1 ช่อง) — ไม่งั้นของแต่งรอบโต๊ะสองคนทับกันหมด · ไม่วางกลางห้องประชุม / มุมกาแฟ / ทางออก
2. **เลือกของจากแคตตาล็อก 25 ชิ้น** แล้วคลิกช่องเขียว (เลือกค้างไว้วางต่อได้หลายชิ้น)

| หมวด | ของ |
|---|---|
| บนโต๊ะ (วางได้ 3 ชิ้น: ซ้าย / ขวา / หน้าจอ) | แก้วกาแฟ (มีไอร้อน) · โน้ตบุ๊ก · จอคู่ · โคมไฟ (แสงเรือง) · กรอบรูป · กองหนังสือ · กระบองเพชร · หูฟัง · ถ้วยรางวัล · เป็ดยาง · โพสต์อิท · ลูกโลก |
| ต้นไม้ | มอนสเตอร่า · เฟิร์น · ลิ้นมังกร |
| เฟอร์นิเจอร์ | ชั้นหนังสือ · พรมกลม · บีนแบ็ก · โคมไฟตั้งพื้น · ตู้เย็นมินิ |
| ของเล่น | ตู้ปลา (ปลาว่าย ฟองลอย) · กีตาร์ · แมวนอนขด (z z z) · ตู้เกม · จักรยาน |

3. **คลิกของที่วางแล้ว = เลือก** → **หมุน 90°** (R) · **กลับซ้าย-ขวา** (F) · **ลบ** (Delete) · คลิกช่องว่าง = ย้ายไปที่นั่น · คลิกซ้ำบนโต๊ะ = วนเลือกชิ้นถัดไป · Esc เลิกเลือก
4. **ย้ายโต๊ะ** — ของแต่งย้ายตามโดยรักษาตำแหน่งเดิมรอบโต๊ะ (ชิ้นที่ที่ใหม่วางไม่ได้จะเอาออกและบอกจำนวน) · **คืนโต๊ะ** = ล้างทั้งหมด
5. **บันทึก** (หรือยกเลิก — ระหว่างแต่งเป็นแค่ร่าง ไม่เขียน SharePoint ทุกคลิก) · บันทึกแล้วทุกคนเห็นภายใน 1 นาที

**กติกา** (กันแต่งจนรบกวนคนอื่น):
- วางได้เฉพาะ**รอบโต๊ะตัวเอง 3 ช่อง** (พื้นที่ 7×7 · มีกรอบเส้นประบอกขอบเขต) · ไม่ทับของคนอื่น ไม่ทับโต๊ะคนอื่น · สูงสุด 24 ชิ้น
- ของวางพื้นต้องอยู่**โซนเดียวกับโต๊ะ** — รัศมี 3 ช่องเลยกำแพงไปถึงห้องประชุม/มุมกาแฟได้ ซึ่งเป็นพื้นที่ส่วนกลาง (เจอตอนขยายจาก 2 เป็น 3 ช่อง)
- ของแต่ง**เดินผ่านได้** ไม่ขวางทาง — แต่งจนปิดทางเดิน หรือขังตัวเองไว้ไม่ได้
- จองโต๊ะชนกันพอดี → ตอนบันทึกจะตรวจใหม่และบอกให้เลือกโต๊ะอื่น
- อ่านข้อมูลแบบไม่เชื่อ: JSON เสีย / ของชนิดที่ไม่รู้จัก / มุมหมุนแปลก ๆ ถูกทิ้งหรือแก้ — แผนที่ไม่มีวันพังเพราะข้อมูลของคนใดคนหนึ่ง

**ทดสอบแล้วบนเบราว์เซอร์**: เห็นโต๊ะเกมมิ่งที่ก้องวางเอง (ตู้เกม บีนแบ็ก หูฟัง) · วางโต๊ะของฉันได้ 145 ช่อง · เลือกแบบผู้บริหารแล้ววาง · วางต้นไม้บนโต๊ะถูกปฏิเสธ (บั๊กที่เทสต์จับได้ก่อนส่ง: ช่องโต๊ะส่วนตัวเป็นพื้น ของวางพื้นเคยวางทับโต๊ะได้) · ของบนโต๊ะไฮไลต์เฉพาะโต๊ะตัวเอง · ของวางพื้นไฮไลต์ 12 ช่องรอบโต๊ะ · วางนอกรัศมีถูกปฏิเสธพร้อมเหตุผล · หมุน/กลับด้านด้วย R/F · บันทึกแล้วของยังอยู่

### โต๊ะส่วนตัว 3×3 ช่อง

โต๊ะ 1 ตัวกินพื้นที่ **3×3 ช่อง** (เดิม 1 ช่อง) — คลิกช่องเขียว = ตำแหน่ง**กลางโต๊ะ**

```
┌───┬───┬───┐
│ ☕ │ 🖥 │ 🎧 │  ← ตัวโต๊ะ (6 ช่อง) เดินผ่านไม่ได้ · ของบนโต๊ะวางที่ 4 มุม
├───┼───┼───┤     (จอกลางแถวบน กับคีย์บอร์ดกลางโต๊ะ เป็นของโต๊ะเอง)
│ 📚 │ ⌨ │ 🪴 │
├───┼───┼───┤
│   │ 🪑 │   │  ← แถวที่นั่ง เดินเข้าไปนั่งได้
└───┴───┴───┘
```

- **ตัวโต๊ะขวางทางเดินจริง** — เดินชน / คลิกเดินอ้อมเอง · แถวที่นั่งเดินเข้าไปนั่งได้
- **วางที่ปิดทางเดินไม่ได้** — ระบบนับพื้นที่ที่เดินถึงกันก่อน/หลังวาง ถ้าวางแล้วมีส่วนที่เดินไปไม่ถึง (เช่น ปิดปากทางเดินแคบ) จะปฏิเสธพร้อมเหตุผล · หมุนโต๊ะแล้วปิดทางก็ปฏิเสธเหมือนกัน
- ทั้ง 9 ช่องต้องอยู่บนพื้นโซนเดียวกัน (โซนโต๊ะทำงาน หรือห้องโฟกัส) ไม่ทับกำแพง/โต๊ะส่วนกลาง · ห่างโต๊ะคนอื่นอย่างน้อย 1 ช่องทางเดิน
- **หมุนโต๊ะ** = ทั้งชุดหมุน (ที่นั่งย้ายด้าน) ของบนมุมโต๊ะหมุนตามไปอยู่มุมใหม่ ของวางพื้นอยู่ที่เดิม
- ของวางพื้นรอบโต๊ะ 2 ช่อง (พื้นที่รวม 7×7) · ใครยืนอยู่ตรงที่มีคนเพิ่งวางโต๊ะทับ จะถูกย้ายไปจุดเกิดเอง ไม่ติดอยู่ในโต๊ะ
- **ผังมาตรฐานปรับใหม่**: โต๊ะส่วนกลางเหลือแถวเดียว พื้นที่ที่เหลือเปิดโล่งไว้วางโต๊ะส่วนตัว — วางได้ **39 จุด** (ผังเดิมได้แค่ 5 จุดเพราะโต๊ะส่วนกลางวางถี่ทุก 2 ช่อง) · Admin แก้ผังเองได้ที่ "ผังออฟฟิศ"

**ทดสอบแล้วบนเบราว์เซอร์**: โต๊ะเกมมิ่ง 3×3 ของก้องแสดงเต็ม 3 ช่อง (จอโค้ง ไฟ RGB เก้าอี้เกมมิ่ง ของบนมุมโต๊ะ) · คลิกที่ตัวโต๊ะ = ไม่เดิน · คลิกที่นั่ง = เดินไปนั่ง · กดลูกศรจากที่นั่งเข้าหาโต๊ะ = ชน ไม่ทะลุ

### ปุ่มกระดิ่ง (แจ้งเตือนข้อความใหม่) — แก้บั๊ก "กดไม่ได้"

**บั๊ก:** ปุ่มตั้งให้กดได้เฉพาะตอนยังไม่เคยตอบเบราว์เซอร์ · อนุญาตแล้ว = ปุ่มเขียว**กดไม่ได้** (ปิดไม่ได้) · ถูกบล็อก = ปุ่มเทา**กดไม่ได้** และวิธีแก้อยู่แค่ใน tooltip
(Chrome บล็อกให้เองได้ถ้าเคยกดปิดหน้าต่างขอสิทธิ์ — ในเบราว์เซอร์ทดสอบก็เป็น "denied" อยู่แล้ว)

**ตอนนี้กระดิ่ง = เมนู กดได้เสมอ:**

| สถานะเบราว์เซอร์ | เมนูแสดง |
|---|---|
| ยังไม่เคยถาม | ปุ่ม **อนุญาตการแจ้งเตือน** → อนุญาตแล้วส่งป้ายทดสอบทันที |
| อนุญาตแล้ว | สวิตช์ **เปิด/ปิดป้าย** + ปุ่ม **ส่งป้ายทดสอบ** (ถ้าไม่เห็น ให้ดูโหมด "ห้ามรบกวน/Focus" ของ Windows) |
| ถูกบล็อก | กล่องแดงบอก 3 ขั้นตอนเปิดคืน: คลิก 🔒 หน้า URL → การแจ้งเตือน → อนุญาต → รีเฟรช |

- **เสียงเตือน "ติ๊ง-ต่อง"** (สวิตช์ + ลองฟัง) — **ใช้ได้แม้เบราว์เซอร์บล็อกป้าย** · สร้างด้วย WebAudio ไม่ต้องมีไฟล์เสียง
- สีกระดิ่ง: เขียว = ป้าย+เสียง · ส้ม = เสียงอย่างเดียว · เทา = ปิดหมด · ค่าจำไว้ในเครื่อง
- ทุกที่ที่เตือน (แชทออฟฟิศ / แชทส่วนตัว / ขอคุยเสียง) ใช้ตัวเดียวกัน (`notifyNew`)

## เพลงผ่อนคลายในห้องโฟกัส

เดินเข้า**ห้องโฟกัส** → เสียงผ่อนคลายค่อย ๆ ดังขึ้น (2.5 วิ) · เดินออก → ค่อย ๆ เงียบ (2 วิ) แล้วหยุดทั้งหมด ไม่กิน CPU

| บรรยากาศ | เสียง |
|---|---|
| 🎹 Ambient | คอร์ดนุ่ม Cmaj9 → Am9 → Fmaj9 → G6/9 วนทุก 8 วิ + กระดิ่งเพนทาโทนิกแทรกเบา ๆ (ไม่มีโน้ตเพี้ยนกับคอร์ด) |
| 🌧️ ฝนตก | ฝนพรำเป็นระลอกหนัก-เบา + หยดน้ำกระทบ |
| 🌿 ป่าและลำธาร (ค่าเริ่มต้น) | น้ำไหลกระทบหิน + นกร้องเป็นชุด คนละตัว คนละทิศ (ซ้าย-ขวา) + ใบไม้ไหว |

- การ์ดเพลงโผล่เหนือแผนที่เมื่ออยู่ห้องโฟกัส: เลือกบรรยากาศ · ปรับความดัง · ปิด/เปิด — **จำค่าไว้ในเครื่อง**
- **คุยเสียงกับใครอยู่ → เพลงลดเหลือ 35% เอง** (ได้ยินกันชัด) · เพลงเล่นในเครื่องเราเท่านั้น ไม่ส่งผ่านไมค์
- **สร้างเสียงสดด้วย WebAudio** (oscillator + noise + filter + reverb สังเคราะห์) — **ไม่มีลิขสิทธิ์ ไม่มีไฟล์เพลง** ไม่เพิ่มขนาดเว็บ
- เบราว์เซอร์ไม่ให้เล่นเสียงก่อนผู้ใช้แตะหน้า — ถ้าโหลดหน้ามาในห้องโฟกัสพอดี เสียงจะเริ่มเมื่อคลิก/กดคีย์ครั้งแรก

**ทดสอบแล้วบนเบราว์เซอร์** (ต่อตัววัดระดับเสียงเข้ากับเอาต์พุตจริง): เดินเข้าห้อง → การ์ดขึ้น เสียงดัง · ป่า 0.098 · ฝน 0.087 · Ambient 0.057 · เดินออก → การ์ดหาย เสียง 0 และหยุดทั้งหมด
(รอบแรกป่าเบากว่าแบบอื่น 3–4 เท่า — ปรับแล้ว)

## เสียงธรรมชาติในสวน

- เดินเข้าโซนสวนแล้วจะได้ยินเสียงลม นกร้อง เป็ดร้องเป็นช่วง ๆ และเสียงน้ำ ทั้งหมดสร้างสดด้วย WebAudio จึงไม่มีไฟล์เสียงและไม่มีปัญหาลิขสิทธิ์
- เสียงน้ำจะดังขึ้นเมื่อเดินเข้าใกล้น้ำตกหรือน้ำพุ และแผ่วลงเมื่อเดินห่างออกไป การ์ดในสวนมีแถบบอกระดับเสียงน้ำ
- ปรับความดังหรือปิดเสียงได้จากการ์ดในสวน ระบบจำค่าไว้ในเบราว์เซอร์แยกจากเพลงห้องโฟกัส
- มีเสียงน้ำไหลแบบรินน้ำ "จ๊อก ๆ" เป็นจังหวะ ดังเท่ากันทั่วทั้งสวน ไม่ขึ้นกับระยะ
- กดปุ่ม "ปรับแต่ละเสียง" เพื่อปรับเสียงน้ำตก น้ำไหล ลม นก และเป็ด แยกกันได้ทีละตัว ลากไปที่ 0 คือปิดเสียงนั้น
- ถ้ากำลังคุยเสียงกับใครอยู่ ระบบจะลดเสียงธรรมชาติลงเอง และเสียงจะหยุดเมื่อเดินออกจากสวน
- ค่าเสียงทั้งหมด (ทั้งเพลงห้องโฟกัสและเสียงสวน) บันทึกกับบัญชีด้วย เปิดเครื่องอื่นจะได้ระดับเดิม ต้องเพิ่มคอลัมน์ Sound ใน HD_OfficeDecor ก่อน

## ประหยัด GPU

- ภาพเคลื่อนไหวบนแผนที่ (ต้นไม้ไหว ปลาว่าย น้ำตก ของแต่งโต๊ะ) จะหยุดเองเมื่อหน้าต่างถูกซ่อน ไม่ได้โฟกัส หรือไม่มีการขยับเมาส์และกดคีย์เกิน 1 นาที
- ขยับเมาส์ กดคีย์ หรือกลับมาที่หน้าต่าง ภาพจะเคลื่อนไหวต่อทันที ตำแหน่งคนบนแผนที่ แชท และเสียงยังทำงานตามปกติระหว่างหยุด
- เงาใต้ต้นไม้ ของแต่ง และสิ่งของ เปลี่ยนจากการเบลอแบบคำนวณสดเป็นเงาไล่สีที่เตรียมไว้ล่วงหน้า หน้าตาเหมือนเดิมแต่เบาเครื่องกว่า
